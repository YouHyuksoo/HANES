# 미완료 작업 기록: IQC 품목별 검사항목 확정

- 작성시각: 2026-09-03 16:14 KST
- 작성자: codex
- 작업 범위: `ITEM_MASTERS` IQC 대상 품목과 `IQC_PART_SPECS`/`IQC_PART_SPEC_ITEMS`
- 현재 상태: 사용자결정대기

## 완료한 것

- JSHANES에서 IQC 대상 46개 품목의 활성 AQL 정책 연결을 확인했다.
- 검사항목이 등록된 16개 품목의 검사수준·AQL·판정표 연결이 완결됨을 확인했다.
- 검사항목 없는 IQC 품목이 정책 단위 판정으로 자동 PASS되지 않도록 서버 차단 로직과 테스트를 추가했다.
- JSHANES 적용 전 면제 품목의 잔여 정책 연결 1건, 정규화 기준 고아 연결 0건을 확인했다.
- migration을 세 차례 실행했고 매번 5개 블록이 모두 성공해 재실행 가능성을 확인했다.
- 적용 후 면제 품목 잔여 연결 0건, 고아 연결 0건, IQC 필수 정책 누락 0건을 확인했다.
- `FK_ITEM_MASTERS_IQC_AQL_POLICY`가 `ENABLED/VALIDATED`이며 자식 `COMPANY,PLANT_CD,IQC_AQL_POLICY_CODE`에서 부모 `COMPANY,PLANT_CD,POLICY_CODE`를 참조함을 확인했다.

## 미완료 / 남은 것

- 원자재 20개에 적용할 실제 검사항목·규격·불량등급·검사수준·AQL을 품질 담당자가 확정해야 한다.
- 반제품 8개와 완제품 2개가 실제 IQC 대상인지 확인해야 한다. IQC 대상이면 검사항목을 등록하고, 아니면 `IQC_FLAG='N'`으로 정정한다.

- 유사한 품목명이나 `테스트1` 템플릿만으로 검사항목을 복제하지 않는다.
