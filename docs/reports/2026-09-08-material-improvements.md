## 즐겨찾기 사용법과 영향 범위

사이드바 즐겨찾기 옆 설정 버튼 → 폴더 만들기 → 메뉴별 폴더 선택. 폴더명 변경·삭제도 같은 모달에서 수행한다. 삭제하면 소속 메뉴는 기본 즐겨찾기로 돌아간다. 중첩 폴더와 드래그 정렬은 이번 구현에 포함되지 않는다.

- 화면: `components/layout/{Sidebar,FavoriteSidebar,FavoriteFolderManager}.tsx`
- 상태/API: `hooks/{useMenuFavorites,useMenuFavoriteFolders}.ts`
- 서버: `modules/menu-favorites/{controllers,dto,services}`, 관련 두 entity
- DB: `2026-09-08_menu_favorite_folders.sql`, `docs/database/schema-erd.md`
- 상세 계약: [즐겨찾기 폴더 영향맵](../business-logics/menu-favorite-folders.md)
- 자재 공통 영향: `components/data-grid/{DataGrid,GridSummaryFooter,gridSummary}` → 각 material 컬럼의 `meta.summary`; receiving service → 공용 ReceivingHistoryTable; lot-split service → 품목코드/품목명 검색; `dateTimeKst` → 요청일 표시.

기존 즐겨찾기 전체 저장은 남아있는 메뉴의 폴더 배정을 보존한다. 조회 전/실패 상태의 전체교체는 차단한다. 사업장 전환 중 응답이 와도 요청 당시 캐시만 갱신한다.
