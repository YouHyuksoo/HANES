# HANES MES 채번 규칙

> 원본: `HANES_MES_채번규칙.pdf` (2026-05-19)
> 모든 일별 시퀀스는 **당일 0시 리셋**.

본 문서는 자재 시리얼, 작업지시번호, 박스번호 등 운영 데이터의 채번 표준을 정의한다.
백엔드 서비스, 시드 데이터, 라벨 인쇄, IQC/생산/포장 화면 구현 시 이 문서를 단일 출처로 사용한다.

## 1. 자재 시리얼 채번

### 형식
- `VH1-RM + YYMMDD + - + 5자리 순번(당일)`
- 예) `VH1-RM260519-00001`
- `VH1-RM` 고정 접두 (VH1 = 공장, RM = Raw Material)

### 자재 흐름 — 입하 ▶ 검사 ▶ 입고
| 단계 | 동작 | 라벨 |
|---|---|---|
| 입하 | 시리얼 채번 + 입하실적 생성(동일 트랜잭션) + 입하실적코드 갱신 | **자재라벨 발행** |
| 검사 | 합격/불합격 판정 | 없음 |
| 입고 | 창고 입고 | 없음 |

### 입하실적코드
- 시리얼 테이블에 **별도 컬럼**으로 보관 (시리얼 문자열에는 미포함).
- **동일 품번 + 동일 입하실적코드 = 동일 LOT** 으로 간주.

### 분할 (Split)
- 분할 수만큼 신규 발번. 단 **날짜·순번은 최초 시리얼 기준**으로 채번.
- 원 시리얼은 사용불가 처리. 신규 시리얼은 다음 메타를 계승:
  - 원 시리얼(parent)
  - 최초 시리얼(root)
  - 입하실적코드
- 자재 수불: 원 LOT 전량 OUT → 분할분 IN. 분할 시 라벨 재발행.

### 병합 (Merge)
- **최초 시리얼이 동일한 LOT끼리만** 병합 가능.
- 원 시리얼들은 사용불가 → 새 시리얼로 통합.
- 원 시리얼은 자재 수불 데이터로 추적. 수불은 OUT → IN 순으로 기록. 라벨 재발행.

## 2. 작업지시번호 채번

### 전체 작업지시 코드
- `W + YYMMDD + - + 3자리 시퀀스(당일)`
- 예) `W260519-001`

### 상세 작업지시 코드
- `전체코드 + - + 파트넘버` (BOM의 제품·반제품마다 별도)
- 예) `W260519-001-HNS-A-R1`

### 제품·반제품 시리얼 (첫 공정 실적입력 시 채번 + 생산라벨)
> 시리얼은 상세코드 맨 앞 `W → S`로 치환 (작업지시번호와 구분 목적).

#### 반제품 (묶음 단위)
- `상세코드(W→S) + _ + 4자리 시퀀스`
- 예) `S260519-001-HNS-A-R1_0001`

#### 완제품 (1:1 고유)
- `상세코드(W→S) + _ + 4자리 박스시퀀스 + - + 4자리 박스내수량`
- 예) `S260519-001-HNS-A_0001-0001`
- 완제품은 **박스 번호 채번 불필요** (시리얼 자체가 박스 식별을 포함).

### 불량 시리얼 (반제품 전용)
- `반제품시리얼 + # + 공정코드`
- 예) `S260519-001-HNS-A-R1_0001#FPRS`

### 수리 후 재채번 (반제품)
- 수리검사 합격 시: `상세코드(W→S) + _ + 신규 4자리 + R`
- 예) `S260519-001-HNS-A-R1_0005R`
- 원 시리얼 보유 상태 + **신규 라벨 추가 발행**.
- 불량공정 완료 → 다음공정으로 흐름 복귀 (마지막 공정이면 재공품 재고로).

## 3. 박스 번호 채번 & 라벨

### 박스 번호
- `BX + YYMMDD + 4자리 시퀀스(당일)` — **하이픈 없음**
- 예) `BX2605190001`
- 박스 1개 = 동일 품번 + 동일 LOT (개별 박스 단위 미사용).
- 분할: 나뉜 박스 둘 다 신규 박스번호 발번.
- 병합: 신규 박스번호 발번 (기존 번호 승계 안 함).
- 분할·병합 이력은 별도 보존.
- 완제품은 박스 채번 불필요 (시리얼이 박스 정보 포함).

### 라벨 발행 시점
| 라벨 종류 | 발행 시점 |
|---|---|
| 자재라벨 | 입하 시 · 자재 분할/병합 시 |
| 생산라벨 | 첫 공정 실적입력 시 · 수리 재채번 시 |
| 박스라벨 | '박스라벨 발행' 기능 실행 시 |

### 라벨 재발행 (바코드 손상 대비)
- 자재 현황 / 생산 현황 / 박스포장 현황 화면에서 재발행 버튼 제공.

## 구현 시 주의사항

1. **시퀀스 채번은 DB SEQUENCE.NEXTVAL** 사용. `MAX(SEQ)+1` 금지 ([STATE](../../.ai-coordination/STATE.md) 글로벌 규칙).
2. **당일 리셋 시퀀스**는 (날짜, 종류) 조합으로 별도 SEQUENCE 또는 별도 카운터 테이블 운영. 단일 SEQUENCE에 모듈러 연산 금지.
3. **공장 코드 단축형(VH1)** 매핑은 `PLANTS` 마스터에 short_code 컬럼 또는 매핑 함수 일원화. 하드코딩 금지.
4. **자재구분 코드(RM/SM/FG)** 는 `ITEM_MASTERS.ITEM_TYPE` 기준. 새 자재구분 추가 시 본 규칙도 확장.
5. **입하실적코드**는 시리얼 문자열에 포함되지 않으므로, LOT 식별은 (품번 + 입하실적코드)로 처리.
6. **분할/병합 이력**은 `parent_serial` + `root_serial` 양쪽 추적해야 트리 복원이 가능.
