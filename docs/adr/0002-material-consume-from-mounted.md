# 자재 소비는 설비 장착분에서만, 출고→장착 2단계로 분리하고 예외 경로를 배제한다

## Context

와이어하네스 자재는 **원자재창고 → 공정입고 → 설비 장착 → 차감** 흐름을 따른다. **출고**(창고 담당자)와 **설비 장착**(작업자)은 서로 다른 사람·다른 시점의 행위다. 현재 코드는 출고와 장착이 한 단계로 통합돼 있고(설비 단위 `WIP_MAT_STOCKS`에 바로 적재), 설비 미배정 작업지시는 원자재창고를 직접 차감하는 예외 경로(fallback)가 있다.

## Decision

- **출고(창고 담당자)**: 원자재창고를 차감하고 공정재고(**장착 대기**)를 증가시킨다. 출고 시점에는 설비를 정하지 않는다.
- **설비 장착(작업자)**: **장착 대기** 공정재고를 특정 설비의 **장착됨**으로 전환한다.
- **차감**: 생산실적은 그 공정에 **장착됨** 상태인 공정재고만 차감한다. **장착 대기**는 차감하지 않는다.
- **예외 경로 배제**: "설비 미배정 시 원자재창고 직접 차감" fallback을 폐기한다. 장착됨 재고 없이 실적이 발생하면 우회하지 않고 **오류**로 처리한다.
- **공정별 차감**: 어느 공정에서 어느 자재를 차감할지는 라우팅 `ROUTING_MATERIALS` 배정(BACKFLUSH)을 따른다.
- **재고 위치 2테이블**: 재고는 위치별로 관리한다 — **공정재고**(공정 단위, 장착 대기)는 신규 테이블, **설비재고**(설비 단위, 장착됨)는 기존 `WIP_MAT_STOCKS`를 그대로 사용한다. 같은 자재가 원자재창고 → 공정재고 → 설비재고로 **위치만 이동**하며, 차감은 설비재고에서만 일어난다. 공정재고는 작업지시와 무관한 **공정 공용** 단위(`COMPANY+PLANT+PROCESS_CODE+ITEM_CODE+MAT_UID`)다.

## Considered options

- **출고 = 설비 장착 1단계** → 장착 대기 재고를 추적할 수 없고, 창고 담당자/작업자 역할 분리가 안 됨. 기각.
- **원자재창고 직접 차감 fallback 유지** → 예외 경로가 비정상을 숨김. 프로젝트 원칙(예외 철저 배제, fail loud)에 반해 기각.
- **공정재고를 설비재고(WIP_MAT_STOCKS)에 status 컬럼으로 통합(1테이블)** → 장착 대기(공정 단위)와 장착됨(설비 단위)은 단위가 달라 EQUIP_CODE를 nullable PK로 만들어야 하고 집계가 지저분해짐. 위치별 2테이블이 정합. 기각.

## 구현 현황 (2026-06-27)

- ✅ **예외 경로 배제(fallback 폐기)**: `auto-issue.service`에서 설비 미배정 시 원자재창고 직접 차감(`issueFifo`)을 제거하고 오류로 막도록 구현 완료. 차감은 설비재고(`WIP_MAT_STOCKS`)에서만.
- ⏳ **출고→공정재고→설비재고 2단계 재배선**: 미구현. 현재는 출고가 설비재고로 바로 적재(1단계). 공정재고 신규 테이블/서비스 및 출고·장착 흐름 전환은 후속 작업(영향 범위: `mat-issue`(출고/취소 대칭), `equip-material`(mount/unmount), MAT_LOTS 정합, 관련 spec/화면).
