# 하네스 전선 사양 분리 설계

## 목적

전선 원자재 품목은 규격, 색상, 단위처럼 구매/재고 기준 속성만 가진다. 제품별 절단 길이와 스트리핑 길이는 품목 고유 속성이 아니므로 `HARNESS_CIRCUIT_SPECS`의 회로별 제조 사양으로 관리한다.

## 설계

- `ITEM_MASTERS.LENGTH`, `STRIP_BEFORE`, `STRIP_AFTER`는 `/master/part` 화면/API/엔티티에서 제거한다.
- `BOM_MASTERS`는 제품별 자재 구성과 소요량의 기준으로 유지한다.
- `HARNESS_CIRCUIT_SPECS.WIRE_ITEM_CODE`를 추가해 회로별 전선 사양이 실제 BOM 자재 품목을 참조하게 한다.
- 회로 저장 시 `WIRE_ITEM_CODE`는 도면 품목의 활성 BOM 자재에 존재해야 한다.
- `ROUTING_MATERIALS.CIRCUIT_ID`를 추가해 공정별 투입 자재가 특정 회로 사양과 연결될 수 있게 한다.

## 운영 흐름

1. 품목관리에서 전선 원자재는 전선 규격/색상/단위만 등록한다.
2. BOM에서 완제품 또는 반제품에 필요한 전선 품목과 소요량을 등록한다.
3. 제품 도면관리에서 회로별 전선 품목, 절단 길이, Strip A/B, 터미널/하우징을 등록한다.
4. 라우팅 자재 편집에서 BOM 자재를 공정에 배치하고, 필요하면 회로 사양을 선택해 절단/압착 공정 조건과 연결한다.

## 검증

- `/master/part` 구조 테스트로 품목 화면/API/엔티티에서 길이/스트리핑 필드가 제거됐는지 확인한다.
- 제품 도면관리 구조 테스트로 `wireItemCode` 입력/저장 계약을 확인한다.
- 라우팅 자재 구조 테스트로 `circuitId` 연결 계약을 확인한다.
- 백엔드 단위 테스트로 회로 저장 시 BOM에 없는 전선 품목을 거부하는지 확인한다.
