# Common Tour Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 전체 메뉴에서 켜고 끌 수 있는 투어 모드와 다국어 상세 설명을 만들고, `/master` 기준정보 화면에 우선 적용한다.

**Architecture:** 헤더의 전역 토글은 사용자·회사·사업장별 localStorage 설정을 읽는 `TourModeProvider`가 관리한다. 화면은 `HelpTarget` 또는 DataGrid `meta.helpKey`만 선언하고, 별도 i18next `tour-help` namespace가 제목·설명·사용법을 제공한다. 기존 `HelpTooltip`은 PC 호버/포커스 렌더러로 재사용하고 PDA에는 탭 기반 dialog 패널을 추가한다.

**Tech Stack:** Next.js/React, TypeScript, i18next, TanStack Table/DataGrid, React Testing Library/Playwright, Node test.
