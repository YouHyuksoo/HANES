# BOM관리

## 화면 목적
완제품·반제품이 어떤 **자품목(자재)으로 구성되는지**를 정의하는 **자재명세서(BOM)**를 관리합니다. 여기 등록된 구성이 생산 시 자재 소요량 계산(전개)과 투입의 기준이 됩니다.

## 화면 구성
- **왼쪽**: 부모품목(완제품/반제품) 선택.
- **오른쪽**: 선택한 부모품목의 **BOM 트리**. 자품목이 다시 하위 자품목을 가지면 **레벨(Lv)**로 펼쳐집니다(재귀 구조). 행을 접기/펼치기(전체 접기·펼치기) 할 수 있습니다.
- **엑셀 업로드**: 여러 BOM 행을 한 번에 등록합니다.
- 행 추가/수정은 BOM 폼에서, 자품목의 공정 라우팅도 함께 확인할 수 있습니다.

## 개념 관계
```
부모품목(완제품) ─┬─ 자품목 A (소요량)
                 ├─ 자품목 B (소요량)
                 └─ 반제품 C (소요량) ─┬─ 자품목 C1
                                       └─ 자품목 C2
```

---

## BOM 컬럼 (BOM_MASTERS)

| 컬럼 | 역할 / 의미 |
|------|------|
| **Lv(레벨)** | BOM 트리에서의 깊이입니다. 부모 바로 아래가 1, 그 자품목이 또 부모가 되면 2…로 펼쳐집니다(저장값이 아니라 트리 계산값). |
| **자품목코드(childItemCode)** | 부모를 구성하는 **자품목의 코드**입니다. 품목마스터에 등록된 품목이어야 합니다. (부모+자품목+리비전이 한 행의 키) |
| **자품목명(childPartName)** | 자품목의 이름입니다(품목마스터에서 가져옴, 표시용). |
| **유형(type)** | 자품목의 품목유형입니다(원자재/반제품 등, 품목마스터 값). 반제품이면 하위 BOM으로 더 전개됩니다. |
| **공정(oper)** | 이 자품목이 **투입되는 공정**입니다. 어느 공정에서 소요되는지 지정. |
| **소요량(qtyPer)** | 부모 1개를 만드는 데 필요한 이 자품목의 **수량**입니다. 생산수량 × 소요량으로 총 필요량을 계산합니다. |
| **리비전(revision)** | BOM 구성의 리비전입니다(기본 `A`). 같은 부모-자품목이라도 리비전으로 버전을 구분합니다(키의 일부). |
| **사이드(side)** | 양면 기판 등에서 적용 면(예: TOP/BOT)을 구분하는 값입니다. |
| **유효시작(validFrom)** | 이 BOM 행이 적용되기 시작하는 날짜입니다. |
| **유효종료(validTo)** | 이 BOM 행의 적용이 끝나는 날짜입니다. (기간 외에는 미적용) |

### 폼에서 함께 입력하는 항목
| 컬럼 | 역할 / 의미 |
|------|------|
| **순번(seq)** | 같은 부모 안에서 자품목 표시/처리 순서입니다. |
| **BOM 그룹(bomGrp)** | BOM을 그룹으로 묶어 관리할 때 쓰는 분류값입니다. |
| **ECO 번호(ecoNo)** | 설계변경(ECO) 추적 번호입니다. 변경 근거 관리. |
| **비고(remark)** | 메모입니다. |
| **사용여부(useYn)** | `Y`일 때만 유효한 구성으로 사용됩니다. |

## 사용 순서
1. 왼쪽에서 **부모품목**을 선택합니다.
2. 오른쪽 트리에서 행을 선택하고 **자품목을 추가**합니다(자품목코드·소요량·공정·유효기간 입력).
3. 자품목이 반제품이면, 그 반제품을 부모로 다시 하위 BOM을 구성합니다.
4. 다건은 **엑셀 업로드**로 한 번에 등록할 수 있습니다.

## 입력 규칙
- 자품목코드는 품목마스터에 존재해야 합니다.
- 소요량은 0보다 커야 합니다.
- 같은 부모+자품목+리비전 조합은 중복될 수 없습니다(한 행의 키).

## 자주 묻는 질문
- **Q.** 레벨(Lv)은 어떻게 정해지나요?
  **A.** 직접 입력이 아니라, 자품목이 다시 BOM을 가지면 자동으로 한 단계 깊어집니다(재귀 전개).
- **Q.** 소요량은 무엇 기준인가요?
  **A.** 부모 1개를 만들 때 필요한 자품목 수량입니다. 총 필요량 = 생산수량 × 소요량.
- **Q.** 리비전은 왜 키에 포함되나요?
  **A.** 같은 부모-자품목이라도 사양 변경(리비전)별로 다른 구성을 둘 수 있기 때문입니다.
