# 수입검사(IQC)

## 화면 목적
입하된 자재 LOT를 품질 검사하여 **합격(PASS) / 불합격(FAIL)**을 판정하는 화면입니다.
품목마스터에서 `IQC 여부 = Y`로 설정된 품목은 입하 후 검사대기(PENDING) 상태가 되며, 이 화면에서 검사를 수행해야 입고 처리로 이어집니다.

> 검사 대상은 입하번호 + 품목 단위로 묶여 표시됩니다. 한 입하건에 같은 품목이 여러 시리얼로 들어온 경우 1행으로 집계됩니다.

## 화면 구성
- **상단 필터 바**: 검색어(입하번호·품목코드·품목명), 검사구분(FULL/SKIP) 필터, 검사상태 필터
- **목록 그리드**: 검사 대기·진행 중·완료 건을 표 형식으로 표시. 행마다 **검사** 버튼
- **검사 모달**: 행의 검사 버튼 클릭 시 열림. 시리얼 스캔 → 항목별 측정/판정 → 결과 등록

---

## ① 목록 그리드 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| **검사(버튼)** | 선택한 입하건의 검사 모달을 엽니다. 검사상태가 `검사대기` 또는 `검사중`인 건만 활성화됩니다. |
| **입하번호(arrivalNo)** | 입하를 식별하는 번호입니다. 이 번호로 어떤 입하분인지 추적합니다. |
| **입하일(arrivalDate)** | 자재가 입하된 날짜입니다. |
| **공급업체(supplierName)** | 자재를 납품한 협력사(공급업체) 이름입니다. |
| **품목코드(itemCode)** | 검사 대상 품목의 MES 내부 코드입니다. |
| **품목명(itemName)** | 검사 대상 품목의 이름입니다. |
| **검사구분(inspectMethod)** | 품목마스터에 설정된 검사 방식입니다. `검사(FULL)` = 정식 수입검사 수행, `무검사(SKIP)` = 검사 생략. |
| **시리얼수(serialCount)** | 이 입하건에 포함된 자재 시리얼(LOT) 개수입니다. 스캔해야 할 대상 수를 나타냅니다. |
| **총수량(totalQty)** | 모든 시리얼의 수량 합계입니다(단위 포함). |
| **상태(status)** | 검사 진행 상태입니다. 아래 상태값 참조. |
| **검사자(inspector)** | 검사를 수행한 담당자 이름입니다. 검사 완료 후 표시됩니다. |

### 검사상태 값

| 상태 코드 | 표시 | 의미 |
|------|------|------|
| `PENDING` | 검사대기 | 입하 완료 후 검사 전 상태. 이 상태에서 검사를 시작할 수 있습니다. |
| `IQC_IN_PROGRESS` | 검사중 | 검사가 시작되었으나 아직 완료되지 않은 상태. 검사 버튼이 활성화됩니다. |
| `PASSED` | 합격 | 검사 판정 결과 합격. 입고 처리로 이어집니다. |
| `FAILED` | 불합격 | 검사 판정 결과 불합격. 시리얼이 불용창고로 자동 이동됩니다. |

---

## ② 검사 모달 — 입하정보 표시

모달 상단에 입하건의 기본 정보가 고정 표시됩니다.

| 항목 | 역할 / 의미 |
|------|------|
| **입하번호** | 현재 검사 중인 입하건 번호입니다. |
| **공급업체** | 납품 협력사 이름입니다. |
| **시리얼수** | 이 입하건에 속한 전체 시리얼 수입니다. |
| **총수량** | 전체 시리얼의 수량 합계입니다. |
| **품목** | 검사 대상 품목명과 품목코드입니다. |

---

## ③ 검사 모달 — 왼쪽 입력 패널

| 항목 | 역할 / 의미 |
|------|------|
| **시리얼 스캔(입력)** | 검사할 시리얼 바코드를 스캔하거나 직접 입력 후 Enter 합니다. 검사대기 목록에 없는 시리얼은 오류 메시지를 표시합니다. **검사대기 시리얼 조회** 버튼으로 대기 목록을 확인하고 개별 클릭 또는 **전체 추가**로 일괄 등록할 수 있습니다. |
| **스캔 진행 카운터** | `스캔수 / 전체 대기수` 형식으로 진행 상황을 표시합니다. |
| **검사자** | 검사를 수행한 사람 이름을 입력합니다. |
| **비고** | 검사 관련 메모를 입력합니다. |
| **기본시료수** | 품목마스터에 등록된 기본 시료 수량입니다. 검사자가 수정할 수 있습니다. |
| **AQL 샘플수량** | 품목에 연결된 AQL 정책을 기준으로 자동 산출된 권장 시료 수입니다. 검사수준과 검사모드(예: `Normal II`)도 함께 표시됩니다. 항목별 Ac/Re(합격/불합격 판정 개수)를 미리 확인할 수 있습니다. |
| **검사성적서** | PDF·이미지·Excel 파일을 첨부합니다. 결과 등록 후 서버에 저장됩니다. |
| **불량코드** | FAIL 판정이 발생했을 때 불량 유형(공통코드 `DEFECT_TYPE`)과 수량을 입력합니다. 행 추가 버튼으로 여러 불량 유형을 동시에 등록할 수 있습니다. FAIL이 없으면 입력할 수 없습니다. |
| **파괴/전수 검사** | 품목에 파괴검사(DESTRUCTIVE) 또는 전수검사(FULL) 유형의 검사항목이 등록된 경우 표시됩니다. 항목별로 **검사수량**과 **불량수**를 직접 입력합니다. 불량수 1개 이상이면 해당 항목은 FAIL로 처리됩니다. |

---

## ④ 검사 모달 — 중간 패널 (스캔한 시리얼 목록)

스캔 또는 추가한 시리얼이 순서대로 나열됩니다.

| 항목 | 역할 / 의미 |
|------|------|
| **순번** | 스캔 순서 번호입니다. |
| **시리얼(matUid)** | 해당 자재 LOT의 고유 식별자(시리얼)입니다. |
| **판정 상태** | 해당 시리얼의 현재 판정 결과입니다. 모든 검사항목 판정 완료 시 PASS/FAIL이 표시되고, 미완료 시 `대기`로 표시됩니다. |
| **제거 버튼** | 잘못 스캔한 시리얼을 목록에서 제거합니다. |

---

## ⑤ 검사 모달 — 오른쪽 측정 패널

시리얼 목록에서 시리얼을 선택하면 해당 시리얼의 검사항목 표가 오른쪽에 나타납니다.

| 컬럼 | 역할 / 의미 |
|------|------|
| **#** | 검사항목 순번입니다. |
| **검사항목** | 검사할 항목 이름입니다. 불량등급(Critical/Major/Minor) 배지와 AQL 값이 표시될 수 있습니다. |
| **규격(spec)** | 해당 항목의 규격 설명입니다. |
| **하한(LSL)** | 계측값의 하한 합격 기준입니다. 입력값이 이 값 미만이면 자동으로 FAIL 처리됩니다. |
| **상한(USL)** | 계측값의 상한 합격 기준입니다. 입력값이 이 값 초과이면 자동으로 FAIL 처리됩니다. |
| **판정기준** | 육안 검사 등 수치 이외의 합격 기준을 문장으로 설명합니다. |
| **측정값** | LSL/USL이 있는 항목은 숫자를 직접 입력합니다. 범위 내이면 자동으로 PASS 판정됩니다. LSL/USL이 없는 육안 검사 항목은 PASS/FAIL 버튼으로 직접 선택합니다. |
| **판정** | 측정/입력 결과에 따른 합격(✓)/불합격(✗) 아이콘입니다. |

> **검사항목이 없는 품목**: 해당 품목에 IQC 검사항목이 등록되지 않은 경우, 시리얼별로 PASS/FAIL을 수동으로 선택합니다.

---

## 사용 순서

1. 목록에서 검사할 입하건 행을 찾아 **검사** 버튼을 클릭합니다.
2. 모달이 열리면 왼쪽 스캔 입력란에 자재 시리얼을 바코드 스캔 또는 직접 입력 후 Enter 합니다(또는 **검사대기 시리얼 조회 → 전체 추가**).
3. 중간 패널에서 시리얼을 선택하면 오른쪽에 검사항목 표가 나타납니다.
4. 항목별로 측정값을 입력하거나 PASS/FAIL을 선택합니다. LSL/USL이 있으면 자동 판정됩니다.
5. 파괴/전수 검사 항목이 있으면 왼쪽 패널 하단에서 검사수량과 불량수를 입력합니다.
6. FAIL 판정이 있으면 **불량코드**를 선택하고 수량을 입력합니다(필수).
7. 필요하면 **검사성적서** 파일을 첨부합니다.
8. 모달 하단의 **검사결과 등록** 버튼을 클릭하여 결과를 저장합니다.

---

## 입력 규칙 / 검증

- 스캔하지 않은 시리얼(아직 검사 안 한 것)은 판정 없이 등록할 수 없습니다.
- 스캔한 시리얼 중 판정이 끝나지 않은 것이 있으면 등록 버튼이 비활성화됩니다.
- FAIL 판정(시리얼 또는 파괴검사)이 있으면 **불량코드를 최소 1건 이상** 입력해야 합니다.
- FAIL이 없는데 불량코드를 입력하면 등록이 차단됩니다.
- 스캔한 시리얼이 검사대기 목록에 없는 번호이면 오류 메시지를 표시하고 등록하지 않습니다.

## 자주 묻는 질문

- **Q.** 검사 버튼이 비활성화됩니다.
  **A.** 해당 입하건의 상태가 `PASSED` 또는 `FAILED`로 이미 판정이 완료된 경우입니다. 판정을 취소하려면 운영자에게 문의하세요.
- **Q.** AQL 샘플수량이 표시되지 않습니다.
  **A.** 해당 품목에 AQL 정책이 연결되어 있지 않습니다. 품목마스터에서 AQL 정책을 설정해 주세요.
- **Q.** 시리얼 스캔 시 "검사대기 시리얼이 아닙니다" 오류가 납니다.
  **A.** 스캔한 시리얼이 현재 PENDING 상태가 아니거나 다른 입하번호에 속한 경우입니다. **검사대기 시리얼 조회**로 올바른 시리얼 목록을 확인하세요.
- **Q.** 불합격 처리 후 재고가 사라졌습니다.
  **A.** IQC 불합격 시 해당 시리얼은 자동으로 불용창고로 이동됩니다. 재검사가 필요하면 운영자에게 취소 요청을 하세요.
- **Q.** 검사항목이 없을 때 어떻게 판정하나요?
  **A.** 품목에 IQC 검사항목이 등록되지 않은 경우, 모달 오른쪽 영역에서 시리얼별로 PASS/FAIL 버튼을 직접 클릭해 판정합니다.
- **Q.** 파괴검사 항목만 있고 시리얼 스캔이 없어도 됩니까?
  **A.** 네. AQL 시리얼 검사항목이 없고 파괴/전수 검사 항목만 있는 경우, 시리얼 스캔 없이 파괴검사 수량만 입력하고 결과를 등록할 수 있습니다.
