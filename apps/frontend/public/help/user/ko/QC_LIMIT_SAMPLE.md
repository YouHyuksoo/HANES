# 양불마스터

## 화면 목적
검사에 쓰는 **한도견본**(이 정도까지는 양품 / 이 정도면 불량이라는 경계 샘플)을 등록하고, 각 견본의 **유효기간·승인 정보·보관 위치·사진**을 관리하는 화면입니다.
유효기간이 지났거나 30일 안에 끝나는 견본은 목록에서 배지로 바로 알 수 있어, 고객 감사에서 요구하는 "한도견본 유효성 관리"에 대응합니다.

**통전·단자검사와 연결됩니다.** 여기에 `적용 검사유형`과 `대조 필수 = Y`로 등록한 견본은, 해당 품목의 통전검사(`/inspection/result`)·단자검사(`/inspection/terminal-result`) 화면에서 **[양/불체크 시작]** 대조 대상으로 나옵니다. 작업자가 견본 바코드를 스캔하고 검사기 결과를 입력하면 결과가 이력으로 남고, 대조를 끝내기 전에는 합격·불합격 판정을 등록할 수 없습니다.
- **견본 바코드 = 견본 코드(sampleCode)** 입니다. 별도 바코드 항목이 없으므로 실물 견본에 견본 코드 라벨을 붙이고 같은 코드로 등록하세요.
- 유효기간이 지난 필수 견본이 있으면 대조 자체가 막히고 검사도 진행되지 않습니다. 기준정보에서 유효기간을 갱신해야 합니다.

> 검사홀더·지그 같은 치공구는 이 화면이 아니라 [검사보조구 관리](/master/inspect-aid)에서 관리합니다.

## 화면 구성
- **상단 요약**: 제목 오른쪽에 `만료` 건수와 `30일 내 만료` 건수가 표시됩니다(사용중이고 폐기되지 않은 견본 기준).
- **유형 탭**: `전체 / 양품견본 / 불량견본`. 탭을 누르면 목록이 그 유형만 조회됩니다. 탭을 고른 상태에서 [추가]하면 그 유형이 기본으로 들어갑니다.
- **왼쪽 — 목록(DataGrid)**: 검색·상태·사용여부 필터, 100건 단위 서버 페이징.
- **오른쪽 — 등록/수정 패널**: 상단에 [취소]·[저장]. 기본정보, 대조 설정, 유효기간·승인, 견본 사진, 비고 순서입니다. 다른 행을 클릭하면 패널이 그 행의 값으로 바뀌며, 작성 중 내용이 있으면 확인 창이 먼저 뜹니다.

## ① 목록 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| **관리** | 연필 = 수정, 휴지통 = 삭제(확인 창). |
| **사진** | **대표 사진** 썸네일. 클릭하면 크게 봅니다. 없으면 빈 아이콘. |
| **사진 수** | 이 견본에 등록된 사진 장수. |
| **견본 코드(sampleCode)** | 견본을 구분하는 고유 코드(예: `LS-OK-0001`). 등록 후 변경할 수 없습니다. 실물 바코드와 같은 값입니다. |
| **유형(sampleType)** | 공통코드 `LIMIT_SAMPLE_TYPE` 배지. `OK` 양품견본, `NG` 불량견본. |
| **견본 명칭(sampleName)** | 현장에서 부르는 이름. |
| **적용 검사유형(inspectType)** | 공통코드 `INSPECT_TYPE` 배지. `CONTINUITY` 통전검사, `TERMINAL` 단자검사. 비우면 **전 검사유형 공통**으로 모든 검사에 나옵니다. |
| **대조 필수(requiredYn)** | `Y`이면 검사 시작 전 반드시 대조해야 합니다. |
| **표시순서(sortOrder)** | 대조 모달에서 견본이 나오는 순서. 작은 값이 먼저입니다. |
| **대상 품목(itemCode)** | 이 견본이 적용되는 품목. 비우면 모든 품목에 공용으로 나옵니다. |
| **적용 공정(processCode)** | 이 견본을 쓰는 공정(선택). |
| **대표 불량코드(defectCode)** | 불량견본이 보여주는 대표 불량 유형(불량견본에만). |
| **유효 종료일(validTo)** | 이 날짜까지 견본이 유효합니다. 비어 있으면 유효기간 관리 대상이 아닙니다. |
| **유효기간 상태** | `만료 (n일 경과)` 빨간 테두리, `만료임박 (D-n)` 주황 테두리(30일 이내), `유효`, 또는 `-`(종료일 없음). 서버가 오늘 날짜 기준으로 계산합니다. |
| **상태(status)** | 공통코드 `LIMIT_SAMPLE_STATUS`. `ACTIVE` 사용중, `EXPIRED` 만료, `RETIRED` 폐기. 사람이 직접 바꾸는 값입니다(자동 변경 없음). |
| **보관 위치(location)** | 견본이 놓인 장소(선반·캐비닛 등). |
| **승인자(approvedBy)** | 견본을 승인한 사람. |
| **사용여부(useYn)** | `사용`만 기본 조회됩니다. |

## ② 등록/수정 패널 입력 항목

| 항목 | 역할 / 의미 |
|------|------|
| **견본 코드** (필수) | 신규 등록 시만 입력. 수정 시 잠깁니다. 같은 코드가 있으면 저장이 거부됩니다. |
| **유형** (필수) | `LIMIT_SAMPLE_TYPE`에서 선택(양품견본/불량견본). |
| **견본 명칭** (필수) | 이름. |
| **대상 품목** | 품목 목록에서 선택. 비우면 공용 견본입니다. |
| **적용 공정** | 공정 목록에서 선택(선택 항목). |
| **대표 불량코드** | **불량견본(NG)일 때만** 선택할 수 있습니다. 양품견본은 비활성화되고 저장 시 비웁니다. |
| **적용 검사유형 / 대조 필수 / 표시순서** | 대조 설정 섹션. 검사유형을 비우면 전 검사유형 공통입니다. |
| **유효 시작일 / 유효 종료일** | 유효기간. 시작일이 종료일보다 늦으면 저장할 수 없습니다. 종료일을 넣어야 만료·임박 배지가 계산됩니다. |
| **승인자 / 승인일** | 견본 승인 정보. |
| **상태** | `LIMIT_SAMPLE_STATUS`에서 선택. 만료 확인 후 `EXPIRED`, 더 이상 쓰지 않으면 `RETIRED`로 바꿉니다. |
| **사용여부** | 사용/미사용. |
| **보관 위치** | 자유 입력. |
| **견본 사진** | **여러 장**을 올릴 수 있습니다(JPG/PNG/GIF/WebP, 장당 5MB 이하). 각 장에 설명(촬영 각도, 불량 부위 등)을 달고, 라디오로 **대표 1장**을 지정합니다. 대표 사진이 목록 썸네일과 대조 모달에 나옵니다. 화살표로 순서를 바꾸고 휴지통으로 한 장씩 지웁니다. |
| **비고** | 자유 메모. |

## 업무 흐름
1. 상단 유형 탭에서 등록할 종류(양품견본 / 불량견본)를 고르고 [추가]를 누릅니다.
2. 코드·명칭을 넣고 대상 품목·공정을 선택합니다. 불량견본이면 대표 불량코드를 고릅니다.
3. 대조 설정에서 적용 검사유형·대조 필수·표시순서를 정합니다.
4. 유효 시작일·종료일, 승인자·승인일을 입력하고 보관 위치를 적습니다.
5. 사진 영역에서 실물 사진을 여러 장 고르고, 각 장에 설명을 달고 대표 1장을 지정한 뒤 [저장]합니다.
6. 실물 견본에 견본 코드 바코드를 붙입니다.
7. 정기적으로(예: 매주) 상단의 `만료`·`30일 내 만료` 건수를 보고, 만료된 견본은 재승인 후 유효기간을 갱신하거나 상태를 `EXPIRED`/`RETIRED`로 바꿉니다.

## 입력 규칙 / 검증
- 견본 코드·유형·명칭은 필수이고, 코드는 테넌트 안에서 유일해야 합니다.
- 유효 시작일 ≤ 유효 종료일.
- 대표 불량코드는 불량견본(NG)에만 저장됩니다.
- 사진은 이미지 파일만, 장당 5MB 이하. 대표 사진은 견본당 1장만 지정됩니다(시스템이 강제).
- 유효기간 상태는 화면이 아니라 서버가 계산하며, `상태` 값은 자동으로 바뀌지 않습니다.

## 자주 묻는 질문
- **Q.** 만료 배지는 뜨는데 상태는 여전히 `사용중`이에요.
  **A.** 배지는 유효 종료일로 자동 계산되고, 상태는 담당자가 확인 후 직접 바꾸는 값입니다. 재승인했다면 종료일을 연장하고, 아니면 상태를 `만료`로 바꾸세요.
- **Q.** 사진을 골랐는데 목록에 안 보여요.
  **A.** 새로 고른 사진은 [저장]을 눌러야 업로드됩니다. 저장 전에 패널을 닫으면 선택이 취소됩니다.
- **Q.** 대표 사진을 두 장 지정할 수 있나요?
  **A.** 없습니다. 대표는 견본당 1장이고, 다른 사진을 대표로 고르면 기존 대표가 자동으로 내려갑니다.
- **Q.** 검사 화면에서 견본이 안 나와요.
  **A.** `사용여부 = 사용`인지, `적용 검사유형`이 그 검사와 맞는지(비우면 모든 검사에 나옴), 대상 품목이 맞는지(비우면 공용) 확인하세요.
