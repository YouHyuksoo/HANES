# 대차관리

## 화면 목적

공정 사이를 오가며 제품·반제품·자재를 담아 옮기는 운반 도구(대차/트레이/매거진)를 등록하고 관리한다. 여기서 등록한 대차번호가 있어야 생산 화면(가공 키오스크, 서브조립, 조립)에서 대차를 스캔해 실적을 담을 수 있고, QR 라벨을 인쇄해 실물 대차에 부착한다.

## 화면 구성

- **좌측**: 대차 목록(DataGrid, 서버 페이징). 검색어, 유형, 사용여부로 필터링한다.
- **우측**: 행을 클릭하거나 "추가" 버튼을 누르면 등록/수정 패널이 열린다. 저장/취소 버튼은 패널 **상단**에 있다.
- QR 라벨 인쇄는 목록 행의 프린터 아이콘으로 별도 모달을 연다.

## ① 대차 목록 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| 관리 | 수정(연필), QR 라벨(프린터), 삭제(휴지통) 아이콘 |
| 대차번호 | 대차를 식별하는 고유 번호(등록 후 수정 불가) |
| 유형 | **카트(CART)** · **트레이(TRAY)** · **매거진(MAGAZINE)** 중 하나(공통코드 `CARRIER_TYPE`) |
| 이름 | 대차를 구분하기 위한 별칭(선택) |
| 수용량 | 이 대차에 담을 수 있는 최대 건수. 비어 있으면 "무제한" |
| 사용여부 | Y(사용)/N(미사용). N이면 생산 화면에서 스캔해도 선택할 수 없다 |
| 비고 | 자유 메모 |

## ② 등록·수정 패널 항목

| 항목 | 역할 / 의미 |
|------|------|
| 대차번호 | 필수. 신규 등록 시에만 입력 가능(수정 시 잠김) |
| 유형 | 필수. 카트/트레이/매거진 선택 |
| 이름 | 선택 입력 |
| 수용량 | 비우면 무제한. 값을 넣으면 1 이상의 정수만 허용되고, 생산 화면에서 그 수만큼 담긴 뒤에는 실적 저장이 막힌다 |
| 사용여부 | Y/N |
| 비고 | 자유 메모 |

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| 추가 | 새 대차를 등록할 때 | 우측 패널을 빈 값으로 연다 | 대차번호·유형 입력 후 저장 |
| 새로고침 | 목록을 최신 상태로 다시 볼 때 | 현재 필터 조건으로 재조회 | - |
| 수정(연필 아이콘) | 기존 대차 정보를 바꿀 때 | 우측 패널에 현재 값을 채워서 연다 | 대차번호는 수정할 수 없다 |
| QR 라벨(프린터 아이콘) | 실물 대차에 붙일 라벨을 뽑을 때 | 대차번호 QR과 유형·수용량이 담긴 라벨 모달을 연다 | 모달의 "인쇄" 버튼으로 60×55mm 라벨을 출력한다. QR 값은 대차번호 그대로다(현장 스캔은 이 값을 그대로 읽는다) |
| 삭제(휴지통 아이콘) | 더 이상 쓰지 않는 대차를 지울 때 | 확인창 후 즉시 삭제한다 | 담긴 라벨/LOT이 있어도 검증 없이 지워지므로, 대차현황에서 이 대차가 비어 있는지 먼저 확인 후 삭제한다 |
| 저장(패널 상단) | 등록/수정 내용을 반영할 때 | 신규는 등록, 수정은 갱신 API를 호출한다 | 필수값·수용량 형식이 틀리면 비활성화된다 |
| 취소(패널 상단) | 입력을 버릴 때 | 패널을 닫는다 | 변경 중이면 저장하지 않고 닫을지 확인창이 뜬다 |

## 업무 흐름

1. "추가"로 새 대차를 등록한다(대차번호·유형은 필수).
2. 목록에서 방금 등록한 행의 프린터 아이콘으로 QR 라벨을 인쇄해 실물 대차에 부착한다.
3. 라우팅 관리(`MST_ROUTING`)에서 해당 공정에 "대차 적재" 또는 "대차 자동투입"을 켜 두면, 생산 화면에서 이 대차번호를 스캔해 실적을 담거나 다음 공정으로 자동 투입할 수 있다.
4. 대차가 실제로 어디에 있고 무엇이 담겼는지는 대차현황(`PROD_CARRIER_STATUS`) 화면에서 확인한다.
5. 더 이상 쓰지 않는 대차는 사용여부를 N으로 바꾸거나(권장) 삭제한다.

## 입력 규칙 / 검증

- 대차번호, 유형은 필수이며 대차번호는 등록 후 바꿀 수 없다.
- 수용량은 비워두면 무제한, 값을 넣으면 1 이상의 정수만 허용된다.
- 사용여부가 N인 대차는 생산 화면에서 스캔해도 선택되지 않는다.
- 삭제는 되돌릴 수 없고, 담긴 실적 라벨/LOT 참조 여부를 화면이 자동으로 검증하지 않는다.

## 자주 묻는 질문

**Q. 대차 유형은 왜 카트/트레이/매거진 세 가지뿐인가요?**
공통코드 `CARRIER_TYPE`으로 관리되는 고정 목록이다. 새 유형이 필요하면 공통코드 관리에서 추가해야 한다.

**Q. QR 라벨의 QR 값은 무엇을 담고 있나요?**
대차번호 문자열 그대로다. 현장에서 이 QR을 스캔하면 그 값이 곧바로 대차번호로 인식된다.

**Q. 수용량을 넘겨서 담으려 하면 어떻게 되나요?**
생산 화면(가공 키오스크 등)에서 실적 저장이 거부되고, "대차가 가득 찼습니다" 안내가 뜬다. 다른 대차를 스캔해야 한다.

**Q. 등록한 대차를 삭제했는데 실적에 남아있던 대차번호는 어떻게 되나요?**
현재 삭제는 참조 검증 없이 즉시 지워진다. 삭제 전 대차현황에서 이 대차가 비어 있는지 반드시 확인한다.

## 관련 화면

- 대차현황(`PROD_CARRIER_STATUS`) — 대차의 현재 위치와 담긴 내용 조회
- 라우팅 관리(`MST_ROUTING`) — 공정별 "대차 적재"/"대차 자동투입" 사용 여부 설정
- 실적입력(키오스크/서브공정/조립) — 실제로 대차를 스캔해 담는 화면
