# 검사보조구 관리

## 화면 목적
검사할 때 제품을 고정·정렬하거나 관찰을 돕는 **검사홀더·지그**를 등록하고, 각 보조구의 **유효기간·승인 정보·보관 위치·사진**을 관리하는 화면입니다.
유효기간이 지났거나 30일 안에 끝나는 보조구는 목록에서 배지로 바로 알 수 있어, 고객 감사에서 요구하는 "검사 치공구 유효성 관리"에 대응합니다.

> **양품·불량 한도견본은 여기가 아닙니다.** 한도견본은 2026-09-16부터 [양불마스터](/master/limit-sample) 화면으로 분리됐습니다. 통전·단자검사의 양/불체크 대조도 그쪽 데이터를 씁니다. 이 화면은 대조 대상이 아닌 치공구만 다룹니다.

## 화면 구성
- **상단 요약**: 제목 오른쪽에 `만료` 건수와 `30일 내 만료` 건수가 표시됩니다(사용중이고 폐기되지 않은 보조구 기준).
- **왼쪽 — 목록(DataGrid)**: 검색·상태·사용여부 필터, 100건 단위 서버 페이징.
- **오른쪽 — 등록/수정 패널**: 상단에 [취소]·[저장]. 기본정보, 유효기간·승인, 사진, 비고 순서입니다. 다른 행을 클릭하면 패널이 그 행의 값으로 바뀌며, 작성 중 내용이 있으면 확인 창이 먼저 뜹니다.

## ① 목록 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| **관리** | 연필 = 수정, 휴지통 = 삭제(확인 창). |
| **사진** | 등록된 사진 썸네일. 클릭하면 크게 봅니다. 없으면 빈 아이콘. |
| **보조구 코드(aidCode)** | 보조구를 구분하는 고유 코드(예: `HD-CONT-001`). 등록 후 변경할 수 없습니다. |
| **유형(aidType)** | 공통코드 `INSPECT_AID_TYPE` 배지. 현재는 `HOLDER` 검사홀더/지그 하나입니다. |
| **보조구 명칭(aidName)** | 현장에서 부르는 이름. |
| **대상 품목(itemCode)** | 이 보조구가 적용되는 품목(선택). |
| **적용 공정(processCode)** | 이 보조구를 쓰는 공정(선택). |
| **유효 종료일(validTo)** | 이 날짜까지 보조구가 유효합니다. 비어 있으면 유효기간 관리 대상이 아닙니다. |
| **유효기간 상태** | `만료 (n일 경과)` 빨간 테두리, `만료임박 (D-n)` 주황 테두리(30일 이내), `유효`, 또는 `-`(종료일 없음). 서버가 오늘 날짜 기준으로 계산합니다. |
| **상태(status)** | 공통코드 `INSPECT_AID_STATUS`. `ACTIVE` 사용중, `EXPIRED` 만료, `RETIRED` 폐기. 사람이 직접 바꾸는 값입니다(자동 변경 없음). |
| **보관 위치(location)** | 보조구가 놓인 장소(선반·캐비닛 등). |
| **승인자(approvedBy)** | 보조구를 승인한 사람. |
| **사용여부(useYn)** | `사용`만 기본 조회됩니다. |

## ② 등록/수정 패널 입력 항목

| 항목 | 역할 / 의미 |
|------|------|
| **보조구 코드** (필수) | 신규 등록 시만 입력. 수정 시 잠깁니다. 같은 코드가 있으면 저장이 거부됩니다. |
| **유형** (필수) | `INSPECT_AID_TYPE`에서 선택(검사홀더/지그). |
| **보조구 명칭** (필수) | 이름. |
| **대상 품목** | 품목 목록에서 선택(선택 항목). |
| **적용 공정** | 공정 목록에서 선택(선택 항목). |
| **유효 시작일 / 유효 종료일** | 유효기간. 시작일이 종료일보다 늦으면 저장할 수 없습니다. 종료일을 넣어야 만료·임박 배지가 계산됩니다. |
| **승인자 / 승인일** | 승인 정보. |
| **상태** | `INSPECT_AID_STATUS`에서 선택. 만료 확인 후 `EXPIRED`, 더 이상 쓰지 않으면 `RETIRED`로 바꿉니다. |
| **사용여부** | 사용/미사용. |
| **보관 위치** | 자유 입력. |
| **사진** | 클릭해서 파일 선택(JPG/PNG/GIF/WebP, 5MB 이하). 미리보기 위에 마우스를 올리면 휴지통(삭제)이 나타나고, 아래 [사진 변경]으로 교체합니다. **저장을 눌러야 서버에 반영**됩니다. |
| **비고** | 자유 메모. |

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| **새로고침** | 목록·만료 건수 재조회 | 목록과 상단 요약을 다시 불러옴 | — |
| **추가** | 새 보조구 등록 | 빈 패널 | 작성 중 내용 있으면 확인 창 |
| **저장**(패널 상단) | 입력 완료 | 신규 등록 또는 수정 → 사진 선택했으면 이어서 업로드, 사진을 지웠으면 서버 사진 삭제 | 코드·유형·명칭 누락, 시작일>종료일이면 비활성 |
| **취소**(패널 상단) | 중단 | 패널 닫기 | 변경 있으면 확인 창 |
| **연필 아이콘** | 수정 | 행 값으로 패널 채움 | — |
| **휴지통 아이콘(행)** | 삭제 | 확인 창 후 삭제(사진 파일도 삭제) | 되돌릴 수 없음 |
| **사진 영역 클릭 / 사진 변경** | 사진 등록·교체 | 파일 선택 → 미리보기 | 저장 시 업로드 |
| **사진 휴지통** | 사진 삭제 | 확인 창 → 미리보기 제거 | 저장 시 서버에서도 삭제 |
| **검색창** | 코드·명칭·품목·위치로 찾기 | 서버 검색(부분 일치) | — |
| **상태 / 사용여부 필터** | 목록 좁히기 | 서버 필터 | 기본 사용여부 = `사용` |
| **페이지 이동(◀ ▶)** | 100건 초과 | 서버 페이징 | — |

## 업무 흐름
1. [추가]를 누르고 코드·명칭을 넣은 뒤 대상 품목·공정을 선택합니다.
2. 유효 시작일·종료일, 승인자·승인일을 입력하고 보관 위치를 적습니다.
3. 사진 영역을 눌러 실물 사진을 선택한 뒤 [저장]합니다.
4. 정기적으로(예: 매주) 상단의 `만료`·`30일 내 만료` 건수를 보고, 만료된 보조구는 재승인 후 유효기간을 갱신하거나 상태를 `EXPIRED`/`RETIRED`로 바꿉니다.

## 입력 규칙 / 검증
- 보조구 코드·유형·명칭은 필수이고, 코드는 테넌트 안에서 유일해야 합니다.
- 유효 시작일 ≤ 유효 종료일.
- 사진은 이미지 파일만, 5MB 이하.
- 유효기간 상태는 화면이 아니라 서버가 계산하며, `상태` 값은 자동으로 바뀌지 않습니다.

## 자주 묻는 질문
- **Q.** 한도견본을 등록하려는데 유형에 양품/불량 견본이 없어요.
  **A.** 한도견본은 [양불마스터](/master/limit-sample) 화면으로 분리됐습니다. 기존에 이 화면에 있던 견본은 전부 그쪽으로 옮겨졌습니다.
- **Q.** 만료 배지는 뜨는데 상태는 여전히 `사용중`이에요.
  **A.** 배지는 유효 종료일로 자동 계산되고, 상태는 담당자가 확인 후 직접 바꾸는 값입니다. 재승인했다면 종료일을 연장하고, 아니면 상태를 `만료`로 바꾸세요.
- **Q.** 사진을 골랐는데 목록에 안 보여요.
  **A.** 사진은 [저장]을 눌러야 업로드됩니다. 저장 전에 패널을 닫으면 선택이 취소됩니다.
