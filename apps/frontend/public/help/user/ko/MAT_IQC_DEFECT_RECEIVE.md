# IQC불합격자재 불량창고입고

## 화면 목적
수입검사에서 **불합격(FAIL)** 판정된 자재 LOT은 입고 전까지 입하재고에 그대로 남습니다. 이 화면에서 담당자가 불합격 LOT을 확인하고 **불량창고(DEFECT 유형)**를 골라 입고 처리합니다. 해외법인처럼 불합격 자재도 반드시 보관해야 하는 사업장의 표준 흐름입니다.

- 시스템설정 `IQC_FAIL_DEFECT_MOVE_MODE`가 `MANUAL`(기본)일 때 이 화면으로 처리합니다. `AUTO`로 바꾸면 종전처럼 FAIL 저장 시 자동으로 불량창고로 이동하고, 이 화면에는 이력만 남습니다.
- 특채(특별채택) 승인된 LOT은 양품 입고 대상이므로 여기 목록에 나오지 않습니다.

## 화면 구성
- **입고 대기 탭**: 불량창고 입고 대상 LOT 목록(시리얼 단위). 상단에 바코드 스캔 입력란, 검색, 불량창고 선택, 비고, **불량창고 입고** 버튼.
- **입고 이력 탭**: 불량창고 입고/취소 트랜잭션(자동이동 포함). 조회기간 기본 당일. 수동 입고 건은 **입고취소** 가능.

## ① 입고 대기 탭

| 항목 | 설명 |
|------|------|
| **바코드 스캔** | 자재 시리얼을 스캔하면 그 행이 체크됩니다. 입하번호를 스캔하면 그 입하의 대기 LOT 전체가 체크됩니다. 대기 건이 아니면 "불량창고 입고 대기 건이 아닙니다" 오류를 표시합니다. |
| **체크박스** | 스캔 대신 목록에서 직접 고를 수 있습니다. 머리글 체크박스는 전체 선택입니다. |
| **불량창고** | 창고마스터에서 유형이 DEFECT인 사용 중 창고만 나옵니다. 기본창고가 있으면 자동 선택됩니다. |
| **불량창고 입고** | 선택 건수와 총수량을 확인창에서 보고 실행합니다. 입하재고에서 차감되어 불량창고 재고(MAT_STOCKS)로 이동하고, 수불 트랜잭션(구분 IQC_DEFECT_RECEIVE)이 남습니다. 일부 시리얼이 실패하면 나머지는 처리되고 실패 사유가 토스트로 표시됩니다. |

목록 컬럼: 자재 시리얼, 입하번호, 품목코드/명, 거래처, 수량, 입하창고, 불합격 판정일시, 검사자, 불합격 사유(AQL 판정 사유), 입하일.

## ② 입고 이력 탭

| 항목 | 설명 |
|------|------|
| **구분** | 불량창고 입고 / 입고 취소 / 자동이동(IQC FAIL) / 자동이동 취소. 취소된 입고는 취소선으로 표시됩니다. |
| **입고취소** | 수동 입고 건 중 불량창고 재고가 그대로 남아 있는 경우만 가능합니다. 취소하면 불량창고 재고가 차감되고 입하재고로 원복되며, 그 LOT은 다시 입고 대기에 나타납니다. |

## 사용 순서
1. 수입검사(IQC)에서 FAIL 판정을 등록합니다.
2. 이 화면 **입고 대기** 탭에서 라벨의 시리얼(또는 입하번호)을 스캔하거나 체크합니다.
3. 불량창고를 확인하고 필요하면 비고를 입력한 뒤 **불량창고 입고**를 누르고 확인창에서 실행합니다.
4. 결과는 **입고 이력** 탭과 자재재고조회·수불이력에서 확인할 수 있습니다.

## 입력 규칙 / 검증
- IQC 상태가 FAIL이고, 특채가 아니며, LOT 상태가 정상이고, 입하재고 잔량이 있는 시리얼만 입고할 수 있습니다.
- 불량창고는 DEFECT 유형·사용 중 창고만 허용합니다.
- 입고 취소는 불량창고 재고가 이동·사용되지 않았을 때만 가능합니다.
- IQC 판정을 취소(운영자)하면 이 화면에서 한 불량창고 입고도 함께 원복됩니다. 불량창고 재고가 이미 변경됐으면 판정 취소가 거부됩니다.

## 자주 묻는 질문
- **Q.** 불합격 처리했는데 목록에 안 보입니다.
  **A.** 특채 승인된 LOT이거나, 이미 불량창고에 입고(또는 자동이동)된 LOT입니다. 입고 이력 탭을 확인하세요.
- **Q.** 스캔입고(자재입고관리)에서 불합격 LOT이 "입고대기 대상이 아닙니다"로 막힙니다.
  **A.** 정상입니다. 불합격 LOT은 양품 입고가 아니라 이 화면에서 불량창고로 입고합니다.
- **Q.** 예전에는 불합격 즉시 불량창고로 옮겨졌는데요.
  **A.** 시스템설정 `IQC_FAIL_DEFECT_MOVE_MODE`가 AUTO였던 동작입니다. 현재 기본은 MANUAL(수동입고)입니다.
