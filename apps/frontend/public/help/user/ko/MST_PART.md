# 품목마스터

## 화면 목적
MES에서 다루는 **모든 품목(원자재·반제품·완제품·소모품)의 기본정보**를 등록·관리합니다. 여기 등록된 품목이 BOM·생산·자재수불·수입검사·재고의 기준이 됩니다.

## 화면 구성
- **왼쪽(목록)**: 품목 그리드. 상단에서 품목유형·사용여부 필터, 품번/품목명 검색, **ERP 동기화**, **품목 추가**.
- **오른쪽(슬라이드 패널)**: 행의 ✏️(수정) 또는 "품목 추가" 클릭 시 열리는 등록/수정 폼.
- IQC 대상(`iqcYn=Y`) 품목은 별도로 **IQC 검사기준 설정**을 할 수 있습니다.

---

## ① 식별 정보

| 컬럼 | 역할 / 의미 |
|------|------|
| **품목코드(itemCode)** | MES 내부에서 품목을 식별하는 **고유 코드**입니다. 한 번 등록하면 변경하지 않는 것을 원칙으로 합니다(BOM·재고·실적이 이 코드로 연결됨). |
| **품번(itemNo)** | 도면·ERP·고객 문서에서 쓰는 품번입니다. 현업에서 가장 많이 부르는 번호. |
| **품목명(itemName)** | 현장에서 식별할 품목 이름입니다. |
| **고객품번(custPartNo)** | 고객사가 사용하는 품번입니다(출하·라벨 매칭용). |
| **Rev(rev)** | 품목 도면/사양의 리비전입니다. 사양 변경 이력 구분. |
| **마킹문구(markingText)** | 라벨·마킹 설비에 전달할 표시 문구입니다. |

## ② 분류

| 컬럼 | 역할 / 의미 |
|------|------|
| **품목유형(itemType)** | MES 흐름상의 큰 분류입니다. 원자재(RAW_MATERIAL)·반제품(SEMI_PRODUCT)·완제품(FINISHED)·소모품(CONSUMABLE). 자재수불·생산 처리 방식이 이 값에 따라 달라집니다. |
| **품목그룹(productType)** | 제품 계열/품목군 코드입니다(공통코드 PRODUCT_TYPE). 회로사양 등에서 참조. |
| **차종/모델(modelName)** | 차량 모델 또는 차종을 구분하는 관리 특성입니다. |

## ③ 규격

| 컬럼 | 역할 / 의미 |
|------|------|
| **규격(spec)** | 품목 규격·사양·치수 등 보조 설명입니다. |
| **색상(color)** | 전선색 등 품목 색상 정보입니다. |
| **단위(unit)** | 수량을 해석하는 기본 단위입니다(EA 등, 공통코드 UNIT_TYPE). 재고·불출 수량이 이 단위 기준. |

## ④ 수입검사(IQC)

| 컬럼 | 역할 / 의미 |
|------|------|
| **IQC 여부(iqcYn)** | 입고 시 수입검사 대상인지 여부입니다. `Y`면 입고 LOT에 IQC가 적용됩니다. |
| **검사방식(inspectMethod)** | IQC 검사/무검사 등 적용 방식입니다(공통코드 IQC_INSPECT_METHOD). |
| **기본시료수(sampleQty)** | IQC 검사 시 사용할 기본 시료 수량입니다. (AQL로 산출하는 샘플수와는 별개) |
| **AQL 정책(iqcAqlPolicyCode)** | 이 품목에 적용할 **AQL 정책**입니다. 입고 LOT 검사 시 이 정책으로 샘플수·합격(Ac)·불합격(Re)을 자동 산출합니다. 정책은 [AQL 기준관리]에서 등록하며, 비워두면 AQL 자동 판정이 적용되지 않습니다. |

## ⑤ 수량 · 포장

| 컬럼 | 역할 / 의미 |
|------|------|
| **박스수량(boxQty)** | 박스 하나에 장입하는 기준 수량입니다(포장·박스라벨 기준). |
| **최소포장수량(minPackQty)** | 자재 불출 시 최소 단위로 취급할 수량입니다. |
| **LOT 구성단위(lotUnitQty)** | 생산 공정품을 묶음 단위로 처리할 기준 수량입니다. |
| **팔레트 구성단위(packUnit)** | 팔레트 또는 상위 포장 단위 구성 기준입니다. |
| **안전재고(safetyStock)** | 재고 부족 판단에 쓰는 기준 수량입니다. 이 값 미만이면 부족으로 봅니다. |

## ⑥ 유효기간

| 컬럼 | 역할 / 의미 |
|------|------|
| **유효기간(expiryDate)** | 입고 또는 제조 기준 유효기간 **일수**입니다. |
| **유효기간 연장(expiryExtDays)** | 품질 판단 후 유효기간을 연장할 수 있는 **최대 일수**입니다. |

## ⑦ 기타

| 컬럼 | 역할 / 의미 |
|------|------|
| **적재위치(storageLocation)** | 품목별로 고정해 둘 기본 적재 로케이션입니다. |
| **사진(imageUrl)** | 품목 사진입니다. 폼에서 업로드하며, 목록 썸네일로도 표시됩니다. |
| **사용여부(useYn)** | `Y`일 때만 조회·선택·사용 대상입니다. 사용 중지는 `N`. |
| **비고(remark)** | 품목 관리 참고사항입니다. |

## ERP 동기화
상단 **ERP 동기화** 버튼은 ERP의 품목 마스터를 가져와 MES에 **신규 추가/변경**합니다. 실행 전 확인 모달이 뜹니다. 한 번에 수만 건이 들어올 수 있으므로, 의도한 경우에만 실행하세요.

## 사용 순서
1. 상단 **품목 추가**(또는 행 ✏️)로 슬라이드 폼을 엽니다.
2. 식별 정보(품목코드·품번·품목명)와 분류(품목유형)를 입력합니다.
3. 필요 항목(규격·IQC·포장·유효기간 등)을 채우고 저장합니다.
4. IQC 대상이면 **IQC 검사기준**과 품목의 **AQL 정책**을 연결합니다.

## 자주 묻는 질문
- **Q.** 품목코드와 품번은 무엇이 다른가요?
  **A.** 품목코드는 MES 내부 식별자(불변 권장), 품번은 도면/ERP/고객 문서에서 쓰는 번호입니다.
- **Q.** AQL 정책을 비워두면?
  **A.** 입고 검사에서 AQL 자동 판정이 적용되지 않습니다(무검사 또는 수동).
- **Q.** ERP 동기화로 잘못 추가됐어요.
  **A.** ERP-IF로 들어온 품목은 운영자가 정리할 수 있습니다(운영 가이드 참조).
