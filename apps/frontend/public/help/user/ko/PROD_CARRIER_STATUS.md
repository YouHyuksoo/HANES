# 대차현황

## 화면 목적

등록된 모든 대차가 지금 어떤 상태(빈 대차/적재 중/이동 중)이고, 무엇이 몇 건 담겨 있으며, 다음에 어디로 가는지를 한 화면에서 확인한다. 현장에서 대차를 찾지 못하거나 대차에 담긴 내용을 다시 확인해야 할 때, 또는 이동전표를 다시 인쇄해야 할 때 사용한다.

## 화면 구성

- **좌측**: 대차 목록(DataGrid, 서버 페이징). 기본 필터는 "활성(빈 대차 제외)"이라 EMPTY 상태 대차는 보이지 않는다.
- **우측**: 행을 클릭하면 그 대차의 상세(헤더 정보 + 담긴 내용 표)가 우측 패널에 열린다.
- 상단 툴바에서 상태, 적재 공정, 바코드 스캔, 검색어로 목록을 좁힐 수 있다.

## ① 대차 목록 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| 대차번호 | 대차 식별 번호 |
| 상태 | **빈 대차(EMPTY)** · **적재 중(LOADING)** · **이동 중(IN_TRANSIT)**(공통코드 `CARRIER_STATUS`). 담긴 것이 없으면 무조건 빈 대차로 표시된다 |
| 유형 | 카트/트레이/매거진(`CARRIER_TYPE`) |
| 종류 | 담긴 내용의 구분 — SG(서브조립 라벨) / FG(제품 라벨) / MAT(자재 LOT) |
| 품목코드 / 품목명 | 담긴 내용의 대표 품목 |
| 작업지시번호 | 담긴 내용이 속한 작업지시 |
| 적재 공정 | 이 대차에 실적을 담은 공정 |
| 적재수 | 담긴 건수(수용량이 있으면 "건수/수용량"으로 표시) |
| 합계 수량 | 담긴 항목들의 수량 합계 |
| 전표번호 | 이동전표가 발행되었으면 그 번호(미발행이면 "-") |
| 최근 적재 | 가장 최근에 담긴 시각 |

## ② 상세 패널 항목

- **헤더**: 상태 배지, 품목코드/품목명, 작업지시번호, 도착 공정(다음 공정. 없으면 "최종"), 적재수/수용량, 합계 수량.
- **담긴 내용 표**: 바코드, 품목코드, 수량, 적재일시를 담긴 순서대로 보여준다. 담긴 것이 없으면 "빈 대차입니다." 안내만 표시된다.

| 상태 필터 | 빈 대차 포함 여부를 바꿀 때 | 활성(기본)/빈 대차/적재 중/이동 중 중 선택 | - |

## 업무 흐름

1. 기본 목록은 "활성(빈 대차 제외)" 상태만 보여준다. 필요하면 상태·공정·바코드·검색으로 원하는 대차를 좁힌다.
2. 행을 클릭해 상세를 열고, 지금 어떤 품목이 몇 건 담겨 있는지, 다음에 어디로 가는지 확인한다.
3. 전표를 다시 인쇄해야 하면 "이동전표" 버튼으로 A4 인쇄 화면을 열어 인쇄한다.
4. 대차의 상태·내용은 생산 화면에서의 스캔에 따라 실시간으로 바뀐다. 이 화면은 그 결과를 조회만 한다(직접 내용을 편집하지 않는다).

### 대차가 채워지고 비워지는 과정 (참고)

대차의 상태는 이 화면이 아니라 생산 현장의 스캔으로 바뀐다. 라우팅 관리(`MST_ROUTING`)에서 공정별로 "대차 적재"·"대차 자동투입" 플래그를 켜 두면 다음과 같이 동작한다.

- **대차 적재**(출력측): 가공 실적입력(키오스크), 서브조립 실적입력, 조립 실적입력 화면에 출력 대차 슬롯이 나타난다. 빈 대차를 스캔하면 그 공정의 실적(라벨/LOT)이 이 대차에 담기며 상태가 "적재 중"으로 바뀐다. 수용량을 채우면 더 담을 수 없고, 이동전표를 발행하면 상태가 "이동 중"으로 바뀌고 대차가 해제된다.
- **대차 자동투입**(입력측): 위 세 화면 중 하나에서 낱개 라벨 대신 대차번호를 스캔하면, 그 대차에 담긴 라벨/LOT을 화면이 자동으로 한 건씩 처리한다(기존 낱개 투입과 동일한 처리기를 반복 호출).

## 입력 규칙 / 검증

- 이 화면은 조회 전용이며 상세 패널에서 이동전표 재발행 외에는 데이터를 바꾸지 않는다.
- 빈 대차(담긴 것이 0건)는 이동전표를 발행할 수 없다.
- 사용 중지(`사용여부=N`)된 대차는 목록에 나타나지만 생산 화면에서는 새로 선택할 수 없다.

## 자주 묻는 질문

**Q. 기본으로 조회하면 왜 대차가 다 안 보이나요?**
기본 필터가 "활성(빈 대차 제외)"이기 때문이다. 빈 대차까지 보려면 상태 필터를 "빈 대차"로 바꾸거나 필터를 해제한다.

**Q. 상태가 "적재 중"과 "이동 중"은 어떻게 다른가요?**
적재 중은 공정에서 아직 실적을 담고 있는 중이고, 이동 중은 이동전표가 발행되어 다음 공정으로 넘어가는 중이다.

**Q. 담긴 내용의 "종류(SG/FG/MAT)"는 무엇을 뜻하나요?**
SG는 서브조립 라벨, FG는 완제품 라벨, MAT는 자재 LOT을 의미한다.

**Q. 이동전표를 다시 인쇄하면 전표번호가 바뀌나요?**
아니다. 이미 발행된 전표는 같은 전표번호로 "재발행" 표시와 함께 다시 인쇄된다.

## 관련 화면

- 대차관리(`MST_CARRIER`) — 대차 등록/수정, QR 라벨 인쇄
- 라우팅 관리(`MST_ROUTING`) — 공정별 "대차 적재"/"대차 자동투입" 사용 여부 설정
- 실적입력(키오스크/서브공정/조립) — 대차를 실제로 스캔해 채우거나 자동투입하는 화면
