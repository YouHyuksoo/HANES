# 검사결과조회

## 화면 목적
제품 검사결과와 검사 이력을 조회합니다.
## 화면 구성
- **조회 조건**: 기간, 상태, 품목, 바코드, 담당자 등으로 대상을 좁힙니다.
- **목록 그리드**: 처리 대상과 결과를 행 단위로 표시합니다.
- **상세/처리 영역**: 선택 행의 수량, 판정, 시리얼, 승인, 취소 또는 확정 상태를 확인합니다.

## 사용 순서
1. 조회 조건을 업무 기준에 맞춥니다.
2. 목록에서 품목, 바코드/문서번호, 수량, 상태를 확인합니다.
3. 처리 화면이면 대상 상태가 처리 가능한지 확인한 뒤 실행합니다.
4. 처리 후 재조회해 수량과 상태가 의도대로 바뀌었는지 확인합니다.

## 입력 규칙·검증
- 필수 식별값(품목, 바코드, 문서번호, 수량, 담당자)이 없으면 저장 또는 실행할 수 없습니다.
- 완료/취소/출하/폐기처럼 이미 후속 처리된 건은 중복 처리하지 않습니다.
- 수량은 화면별 기준 단위가 다르므로 품목 집계와 시리얼 상세를 분리해 확인합니다.

## 자주 묻는 질문
- **Q. 화면에 대상이 보이지 않습니다.**
  **A.** 기간, 상태, 품목유형, 회사/공장 스코프를 먼저 확인하세요.
- **Q. 처리 후 수량이 예상과 다릅니다.**
  **A.** 집계 테이블과 시리얼/라벨 상세 테이블을 같이 봐야 합니다.

## 검사 준비 4단계 (2026-09-15 추가)
검사기를 고르면 화면 위에 준비 체크바가 뜹니다. **4개가 모두 초록이 되어야 합격·불합격 버튼이 열립니다.** 서버에서도 같은 조건으로 막으므로 화면을 우회해도 등록되지 않습니다.

| 단계 | 내용 | 주기 |
|------|------|------|
| ① 설비일상점검 | 선택한 검사기의 일상점검. 종합판정이 PASS여야 합니다. | 조업일 1회 |
| ② 작업자설비점검 | 작업자가 하는 설비 자가점검. 작업자·작업지시를 먼저 골라야 열립니다. | 작업지시 기준 |
| ③ 양불마스터 대조 | [양/불체크 시작] → 한도견본 바코드 스캔 → 검사기 결과 입력 | 작업지시 × 검사기 × 조업일 × 교대 1회 |
| ④ 소모품 장착 | 좌측 소모성 설비부품이 모두 장착됐는지 | 매핑 기준 |

### 작업자 선택
검사기 선택 옆에서 **[작업자 추가]** 로 작업자를 고릅니다(실적입력(가공) 화면과 같은 방식). 선택한 작업자는 그 검사기의 현재 작업자로 저장되고, 검사 실적의 검사자로 기록됩니다. 작업자가 없으면 판정 버튼이 비활성입니다.

### 양불마스터 대조
- 양품 한도견본은 검사기에서 **합격**이 나와야 정상, 불량 한도견본은 **불합격**이 나와야 정상입니다.
- 견본 바코드(보조구 코드)를 스캔한 행만 합격/불합격 버튼이 열립니다.
- 결과가 불합격(NG)이면 검사가 계속 막힙니다. 검사기를 점검한 뒤 다시 대조하세요. NG 시도도 이력에 남습니다.
- 유효기간이 지난 필수 견본이 있으면 대조가 불가하니 기준정보(검사보조구 관리)에서 갱신하세요.
- **[대조 이력]** 에서 이전 대조 기록과 견본별 판정을 볼 수 있습니다.
