# 고전압 하네스 SPC 관리도

## 화면 목적
고전압 하네스 공정(절단탈피·실드편조절단·압착·육각압착·열수축·조립·종합검사)의 관리 특성(절단 길이, 압착 높이 등)을 X̄-R 관리도로 보고, 공정능력(Cpk)과 관리한계 이탈·패턴 규칙 위반을 한눈에 감시하는 **조회 전용** 화면입니다. 등록·수정 기능은 없습니다.

## 주요 기능
- 관리대상 목록(공정별 그룹)에서 상태 점·Cpk·이탈 수를 훑어보고 문제 특성을 바로 고릅니다.
- 선택한 특성의 X̄ 관리도, R 관리도, 히스토그램을 규격선(LSL/T/USL)과 함께 봅니다.
- 능력지수(Cpk/Cp/Ppk), 총평균, 평균 범위, 군내/전체 산포를 숫자로 확인합니다.
- 규칙 위반(R1~R4, RR1) 목록과 서브그룹 이력(측정값 5개 묶음)을 확인합니다.
- 60초마다 자동으로 다시 조회합니다.

## 화면 구성
- **툴바**: 기간(7/14/30/60일), 서브그룹 k(전체/25/50), 공정 선택, 검색, 조회 구간 표시, 이탈·주의·관리대상 건수 요약. 데이터가 목업이면 우측에 점선 배너 "목업 데이터 — 검사이력 연동 전"이 보입니다.
- **좌측 관리대상 목록**: 공정 코드별로 묶인 특성 행. 행마다 상태 점, 특성명, 품목·n·단위, Cpk, OOC/RULE 건수.
- **우측 상세**: 헤드라인 → 능력지수 스트립 → 관리도 3종 → 규칙 위반 → 서브그룹 표(최신이 위).

## ① 주요 컬럼·입력 항목
| 항목 | 역할 / 의미 |
|------|------|
| 상태 점 | 관리상태(초록) / 주의(황색) / 이탈(적색). 최근 25개 서브그룹 기준으로 서버가 판정합니다. |
| Cpk | 군내 산포 기준 공정능력. 1.33 이상 정상, 1.00~1.33 주의, 1.00 미만 부적합. 규격이 없으면 `-` 또는 `미산출`. |
| Cp / Ppk | Cp는 양측 규격이 있을 때만 산출. Ppk는 전체 산포(군간 포함) 기준. |
| X̿ (총평균) / R̄ (평균 범위) | 관리도 중심선 값. |
| σ 군내 / σ 전체 | R̄/d2 로 추정한 군내 산포와 전체 표본 표준편차. |
| 관리한계 이탈 | R1(X̄ 3σ 밖 1점) + RR1(R 관리도 상한 초과) 건수. |
| 패턴 규칙 | R2·R3·R4(런 규칙) 건수. |
| 규격 | LSL · T · USL. 단측 규격(인장강도 LSL만, 누설전류 USL만)이면 있는 쪽만 표시. |
| 서브그룹 표 | #, 일자, 시각, 설비, LOT, 측정값 5개, X̄, R, 판정(OOC/WARN 배지). |

### 규칙 코드
| 코드 | 의미 | 심각도 |
|------|------|------|
| R1 | 관리한계(3σ) 밖 1점 | 이탈 |
| R2 | 연속 3점 중 2점이 같은 쪽 2σ 밖 | 주의 |
| R3 | 연속 5점 중 4점이 같은 쪽 1σ 밖 | 주의 |
| R4 | 연속 8점이 중심선 같은 쪽 | 주의 |
| RR1 | R 관리도 상한 이탈(산포 급증) | 이탈 |

## 버튼별 기능
| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| 기간 7/14/30/60일 | 조회 구간 변경 | 오늘 포함 최근 N일 서브그룹 재조회 | 관리한계·Cpk 가 구간 기준으로 다시 계산됩니다. |
| 서브그룹 전체/k=25/k=50 | 최근 k개만 볼 때 | 최근 k 서브그룹만으로 관리한계 계산 | 전체와 결과가 다를 수 있습니다. |
| 공정 선택 | 특정 공정만 볼 때 | 목록 필터 | 선택 중이던 특성이 사라지면 이탈 대상 → 첫 항목 순으로 자동 선택. |
| 검색 | 특성·품목·공정 찾기 | 목록 즉시 필터 | 한글 특성명, 영문 특성명, 품목코드, 공정명/코드 대상. |
| 목록 행 클릭 | 상세 보기 | 우측 상세 갱신 | 관리도·규칙 위반·서브그룹 표가 바뀝니다. |

## 업무 흐름
1. 툴바에서 기간과 서브그룹 k 를 정합니다(기본 30일·전체).
2. 좌측 목록에서 적색 상태 점 또는 Cpk 가 낮은 특성을 고릅니다. 첫 진입 시 이탈 대상이 자동 선택됩니다.
3. 우측 X̄ 관리도에서 붉은 점(OOC)과 황색 점(패턴 규칙)의 위치·시각·설비·LOT 를 확인합니다.
4. 규칙 위반 목록과 서브그룹 표에서 해당 측정값 5개를 보고 원인(설비·LOT·시프트)을 추적합니다.
5. 조치 후 재조회해 상태 점이 관리상태로 돌아왔는지 확인합니다.

## 자주 묻는 질문
- **Q.** 툴바에 "목업 데이터" 배너가 보입니다.
  **A.** 검사이력 연동 전이라 서버가 생성한 예시 데이터입니다. 실 검사이력으로 전환되면 배너가 자동으로 사라집니다.
- **Q.** Cp 가 `미산출`로 나옵니다.
  **A.** Cp 는 양측 규격(LSL·USL 모두)이 있어야 산출됩니다. 단측 규격 특성은 Cpk 만 봅니다.
- **Q.** 관리도가 그려지지 않고 "서브그룹이 2건 미만" 문구만 보입니다.
  **A.** 조회 기간 안에 서브그룹이 1건 이하라 관리한계를 계산하지 않았습니다. 기간을 늘리세요.
- **Q.** 한 달 전 이상점이 있는데 상태가 관리상태입니다.
  **A.** 상태 판정은 최근 25개 서브그룹만 봅니다. 관리도에는 전체 구간의 점이 모두 그려집니다.
