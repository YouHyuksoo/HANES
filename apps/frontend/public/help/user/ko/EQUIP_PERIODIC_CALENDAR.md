# 정기점검 캘린더

## 화면 목적
월 단위로 정기점검(PERIODIC)의 현황을 캘린더 뷰로 조회하고, 날짜별 설비의 점검 항목을 확인하며 점검을 실행합니다. 일상점검 캘린더와 동일한 UI를 사용하지만 PERIODIC 유형의 데이터를 표시합니다.

## 화면 구성
- **상단 — 통계 카드**: 해당 월의 전체 점검 스케줄 수, 완료 수, 불합격 수, 미완료(지연) 건수를 요약 표시합니다.
- **좌측 — 캘린더 그리드**: 월별 달력에 날짜별 점검 현황을 색상으로 구분하여 표시합니다.
- **우측 — 일별 설비 점검 패널**: 선택한 날짜의 설비별 점검 대상과 결과를 표시합니다.

## 캘린더 색상 구분

| 상태 | 색상 | 의미 |
|------|------|------|
| **전체합격(ALL_PASS)** | 초록 | 해당일 모든 설비 점검 완료, 전 항목 합격 |
| **불합격있음(HAS_FAIL)** | 빨강 | 해당일 점검 결과에 불합격(FAIL) 포함 |
| **진행중(IN_PROGRESS)** | 노랑 | 일부 설비는 점검 완료, 일부는 미완료 |
| **미시작(NOT_STARTED)** | 회색 | 점검 대상이 있으나 아직 시작하지 않음 |
| **지연(OVERDUE)** | 빨강 테두리 | 점검 기한이 지났으나 미완료 |

## 사용 순서
1. 캘린더에서 날짜를 클릭하여 선택합니다.
2. 우측 패널에 해당일의 설비별 점검 대상 목록이 표시됩니다.
3. 각 설비 카드에서 **점검 실행** 또는 **수정** 버튼을 클릭합니다.
4. 점검 실행 모달에서 점검자 선택, 항목별 PASS/FAIL 판정, 불량 사유를 입력합니다.
5. 저장 후 캘린더와 패널이 자동 갱신됩니다.
