# 관리계획 통합 문서 작업공간

## 사용 순서

1. `신규`를 누르고 품목마스터에서 품목과 단계를 선택합니다.
   최초 발행 전에는 `기본정보 수정`으로 프로젝트·고객·조직·담당자를 보완할 수 있습니다.
2. 기준정보가 준비되어 있으면 `자동 초안`을 눌러 PFD·PFMEA·Control Plan 후보를 만듭니다.
3. PFD 탭에서 공정 순서와 lane·기호를 정리합니다.
4. PFMEA 탭에서 CFT 참여자를 등록하고 PFD 공정, 고장형태·영향·원인, 예방·검출 관리, 권고조치, 담당 조직·담당자, 목표일·완료일을 입력합니다. 조치 전·후 S/O/D와 RPN은 자동 계산됩니다.
5. Control Plan 탭에서 PFD/PFMEA를 연결하고 규격·측정법·시료수·주기·관리방법·반응계획을 입력합니다.
6. `검증` 결과의 오류를 누르면 해당 탭과 행으로 이동합니다.
7. 오류가 없으면 `발행`합니다. 발행본은 읽기 전용입니다.
8. 변경이 필요하면 발행본에서 `개정 생성`을 눌러 새 DRAFT를 만듭니다.
9. `개정이력`에서 같은 문서의 두 Revision을 선택해 머리정보와 추가·삭제·변경 행을 비교합니다.
10. 출력센터에서 공식 PDF 4종을 미리보기·다운로드·인쇄하거나 Excel을 받습니다. 출력 동작은 감사이력에 남습니다.

## 주의사항

- `100%` 검사에서 별도 검사주기를 함께 입력할 수 없습니다.
- 특별특성은 자유입력이 아니라 `★ 안전/법규`, `◈ 기능/조립` 코드에서 선택합니다.
- 발행본은 직접 고치거나 삭제할 수 없습니다.
- CFT 참여자도 PFMEA DRAFT에서만 추가·삭제할 수 있으며, 새 Revision에는 그대로 복제됩니다.
- 행이 없는 빈 문서는 발행할 수 없습니다.
- PDF/Excel은 현재 마스터가 아니라 발행 당시 Revision snapshot을 사용합니다.
