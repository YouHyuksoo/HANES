# 절압물검사

## 화면 목적
전선을 자르고 단자를 압착한 반제품(절압물)을 **조립에 넘기기 전에** 검사하는 화면입니다.
압착 작업지시를 고르면 그 품목 BOM의 단자마다 [단자별 압착 규격]에 등록된 압착고(CH)·압착폭(CW)·절연부 압착고·인장력·탈피길이 기준이 나타납니다. 실측값과 외관 판정을 입력해 등록하면 시스템이 규격과 대조해 합격/불합격을 정합니다.

> 예전 "단자검사" 메뉴가 이 화면으로 바뀌었습니다. 완제품 FG 라벨이나 회로라벨은 쓰지 않습니다.

## 화면 구성
- **왼쪽 — 압착 작업지시 목록**: 공정유형이 압착(CRIMPING)이고 상태가 `진행중`·`대기`인 작업지시입니다. 검색창으로 작업지시번호·품목을 찾습니다.
- **오른쪽 위 — 검사 입력**: 대상 작업지시, 검사자, 시점(초물/중물/종물), 단자별 측정칸, 외관 판정, 비고, [판정 등록] 버튼이 있습니다.
- **오른쪽 아래 — 검사 이력**: 선택한 작업지시에 등록된 절압물검사 결과입니다(최근 100건).

## ① 압착 작업지시 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| **작업지시** | 압착 작업지시번호입니다. 행을 누르면 오른쪽에 검사 입력이 열립니다. |
| **품목명** | 윗줄은 압착 품목코드, 아랫줄은 공정명(예: 일반압착·양단압착)입니다. |
| **상태** | 작업지시 상태(`진행중`/`대기`). 진행중이 위에 먼저 나옵니다. |
| **검사** | 이 작업지시에 등록된 절압물검사 건수입니다. 괄호 안 빨간 숫자는 그중 불합격 건수입니다. |

## ② 검사 입력 항목

| 항목 | 역할 / 의미 |
|------|------|
| **검사자** (필수) | 작업자 마스터에서 고릅니다. 결과의 검사자로 기록됩니다. |
| **시점** | `초물`·`중물`·`종물` 중 하나. 기본값은 초물입니다. |
| **SIDE / 단자 / 전선** | BOM의 단자 자품목과 전선입니다. 괄호 안은 품목 규격(SPEC)입니다. 어플리케이터가 규격에 있으면 함께 보입니다. |
| **압착고(CH)·압착폭(CW)·절연부 압착고·인장력(N)·탈피길이** | 그 단자 규격에 상하한이 있는 항목만 입력칸이 생깁니다. 단자 정보 오른쪽에 한 줄로 놓이고, 칸 위에 항목명과 규격 범위가 보입니다. 입력한 값이 범위 밖이면 칸과 범위가 빨간색으로 바뀝니다. |
| **외관 판정** | 공통코드 `CRIMP_VISUAL_CHECK` 항목(압착형상·이종·누락·외관불량)마다 OK/NG를 고릅니다. |
| **비고** | 불량 상세나 특이사항(300자). 결과의 판정 내용에 함께 남습니다. |

> 단자가 2개인 품목은 단자마다 규격이 다를 수 있습니다. 반드시 **각 단자 칸에** 그 단자의 실측값을 넣으세요.

## ③ 검사 이력 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| **검사시간** | 등록 시각입니다. |
| **시점** | 초물/중물/종물. |
| **판정** | 합격(초록) / 불합격(빨강). |
| **판정 내용** | 불합격 사유입니다. 예: `MAG_TERX00616NA 압착고 1.35 (1.2~1.3)`, `외관 이종 NG`. |
| **검사자** | 검사자 코드. |

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| **새로고침** | 작업지시 목록을 다시 볼 때 | 압착 작업지시와 검사 건수를 다시 조회 | — |
| **작업지시 행** | 검사할 대상을 고를 때 | 오른쪽에 단자별 규격·이력 표시 | 다른 행을 고르면 입력 중인 값은 지워집니다 |
| **초물 / 중물 / 종물** | 검사 시점 지정 | 시점 선택 | 등록 결과에 시점이 남습니다 |
| **OK / NG** | 외관 항목 판정 | 항목별 판정 선택 | NG가 하나라도 있으면 불합격 |
| **판정 등록** | 모든 값을 입력한 뒤 | 서버가 규격과 대조해 합/불 확정 후 저장 | 검사자·모든 측정값·모든 외관 판정이 있어야 눌립니다. 버튼 옆에 `합격 예상`/`불합격 예상`이 먼저 보입니다 |

## 업무 흐름
1. 압착기에서 초물(또는 중물·종물) 시료를 뽑습니다.
2. 왼쪽 목록에서 그 압착 작업지시를 누릅니다.
3. 검사자와 시점을 고릅니다.
4. 단자마다 압착고·압착폭 등을 측정해 입력합니다. 빨간색 칸이 있으면 재측정해 확인합니다.
5. 압착형상·이종·누락·외관불량을 OK/NG로 판정합니다.
6. [판정 등록]을 누르면 아래 검사 이력 제목 옆에 `합격/불합격 · 결과번호 · 사유`가 표시되고 이력에 한 줄이 추가됩니다.
7. 불합격이면 압착 조건(어플리케이터·압착기)을 조치한 뒤 다시 검사합니다.

## 입력 규칙 / 검증
- 측정값은 규격에 상하한이 있는 항목만 받으며, 그 항목은 모두 입력해야 합니다.
- 인장력은 최소값 이상이면 합격, 나머지는 하한~상한 안이면 합격입니다.
- 화면의 `합격 예상`은 참고용입니다. 최종 판정은 서버가 같은 규격으로 다시 계산합니다.
- 규격을 정할 수 없는 단자가 있거나 BOM에 단자가 없으면 빨간 안내만 나오고, 외관 판정·비고·[판정 등록]은 나오지 않습니다(등록 불가).
  - `작업지시 품목 BOM에 단자가 없습니다` — 단자가 아닌 부품을 압착하는 공정입니다(예: 육각압착은 쉴드 링·페룰을 압착). 단자별 압착 규격으로 판정할 대상이 아닙니다.
  - `BOM에서 전선을 찾을 수 없습니다` — 압착 품목 BOM에도, 그 아래 반제품 BOM 어디에도 전선이 없습니다.
  - `BOM 전선이 2종 이상` — 전선이 처음 나오는 BOM 단계에 전선이 2종 이상이라 어느 전선인지 정할 수 없습니다.
  - `압착 규격이 없습니다` / `2건 이상입니다` — [단자별 압착 규격]에 **단자 품목 + 전선 품목**이 정확히 맞는 사용중 규격이 1건이어야 합니다.

## 자주 묻는 질문
- **Q. 작업지시가 목록에 없습니다.**
  **A.** 공정유형이 압착(CRIMPING)이고 상태가 진행중·대기인 작업지시만 나옵니다. 완료·취소된 작업지시는 나오지 않습니다.
- **Q. 규격이 있는데 "압착 규격이 없습니다"라고 나옵니다.**
  **A.** 규격 행에 **전선 품목**이 지정되어 있어야 합니다. 전선 사이즈만 있고 전선 품목이 빈 행은 판정에 쓰지 않습니다. [단자별 압착 규격]에서 그 단자의 전선 품목을 채워 주세요.
- **Q. 예전 단자검사 결과는 어디서 보나요?**
  **A.** 단자검사(FG 라벨 기반)로 등록된 결과는 없었습니다. 절압물검사 결과는 이 화면 아래 이력과 [검사이력] 화면(검사유형 `절압물검사`)에서 봅니다.
