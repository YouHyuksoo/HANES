# 단자별 압착 규격

## 화면 목적
단자(터미널) 품목 하나와 전선 사이즈 하나의 **조합마다 압착 규격**을 정해 두는 화면입니다.
압착 높이(CH)·압착 폭(CW)·절연부 압착고·인장력·탈피길이의 허용 범위를 숫자로 등록하면, 자주검사·계측 판정에서 이 값을 기준으로 합격/불합격을 가릴 수 있습니다.

> 같은 단자라도 전선 굵기가 다르면 규격이 다릅니다. 그래서 **단자 품목 + 전선 사이즈**가 한 건의 열쇠이며, 같은 조합은 두 번 등록할 수 없습니다.

## 화면 구성
- **왼쪽 — 규격 목록(DataGrid)**: 등록된 압착 규격을 표로 보여줍니다. 검색·단자 종류·사용여부 필터와 서버 페이징(100건 단위)이 있습니다.
- **오른쪽 — 등록/수정 패널**: [추가] 또는 행의 연필 아이콘을 누르면 열립니다. 패널 상단에 [취소]·[저장] 버튼이 있고, 다른 행을 클릭하면 패널 내용이 그 행으로 바뀝니다. 작성 중인 내용이 있으면 바꾸기 전에 확인 창이 뜹니다.

## ① 규격 목록 컬럼

| 컬럼 | 역할 / 의미 |
|------|------|
| **관리** | 연필 = 수정 패널 열기, 휴지통 = 삭제(확인 창 후 삭제). |
| **단자 품목(terminalItemCode)** | 규격의 대상 단자 품목코드입니다. 품목마스터(원자재)에 등록된 품목만 선택할 수 있습니다. |
| **단자 종류(terminalType)** | 공통코드 `TERMINAL_TYPE` 배지. `DISK`(디스크)·`RING`(링)·`FASTON`(파스톤)·`PIN`(핀)·`SOCKET`(소켓). 헤더의 물음표를 누르면 종류 설명이 보입니다. 분류용이며 비워 둘 수 있습니다. |
| **전선 사이즈(wireSize)** | 압착하는 전선 굵기 표기입니다(예: `0.5SQ`, `AWG20`). 단자 품목과 함께 한 건을 구분하는 키입니다. |
| **전선 품목(wireItemCode)** | 해당 사이즈의 실제 전선 품목코드(선택). 품목마스터(원자재)에서 고릅니다. |
| **압착고(CH)** | 도체부 압착 높이의 `하한 ~ 상한`(mm). 둘 다 없으면 `-`. |
| **압착폭(CW)** | 도체부 압착 폭의 `하한 ~ 상한`(mm). |
| **절연부 압착고** | 절연부(인슐레이션) 압착 높이의 `하한 ~ 상한`(mm). |
| **인장력 최소(N)** | 압착부를 당겼을 때 견뎌야 하는 최소 힘(뉴턴). 이 값 미만이면 불량입니다. |
| **탈피길이** | 전선 피복을 벗기는 길이의 `최소 ~ 최대`(mm). |
| **어플리케이터(applicatorCode)** | 이 규격에 쓰는 압착기 어플리케이터 코드(선택). |
| **사용여부(useYn)** | `사용`인 규격만 판정에 쓰입니다. 기본 필터는 `사용`입니다. |
| **비고(remark)** | 자유 메모. |

## ② 등록/수정 패널 입력 항목

| 항목 | 역할 / 의미 |
|------|------|
| **단자 품목** (필수) | 원자재 품목 목록에서 선택합니다. 직접 타이핑하지 않습니다. |
| **단자 종류** | `TERMINAL_TYPE` 공통코드에서 선택(선택 항목). |
| **전선 사이즈** (필수) | `0.5SQ`처럼 현장 표기 그대로 입력합니다. 같은 단자에 같은 사이즈가 이미 있으면 저장이 거부됩니다. |
| **전선 품목** | 원자재 품목 목록에서 선택(선택 항목). |
| **어플리케이터** | 압착기 어플리케이터 코드(선택). |
| **사용여부** | 사용/미사용. |
| **압착고 하한/상한, 압착폭 하한/상한, 절연부 압착고 하한/상한** | mm 단위 소수 셋째 자리까지. **하한이 상한보다 크면 저장 버튼이 비활성화**됩니다. |
| **인장력 최소(N)** | 뉴턴 단위 최소값. |
| **탈피길이 최소/최대** | mm 단위. 최소가 최대보다 크면 저장할 수 없습니다. |
| **비고** | 자유 메모. |

> 모르는 값은 **비워 두세요**. 비운 항목은 `-`로 표시되고 판정에 사용되지 않습니다. 임의 숫자를 채워 넣으면 검사에서 잘못된 판정이 납니다.

## 버튼별 기능

| 버튼 | 언제 사용 | 동작 | 결과 / 주의 |
|------|------|------|------|
| **새로고침** | 목록을 다시 불러올 때 | 현재 필터·페이지로 재조회 | — |
| **추가** | 새 규격 등록 | 빈 패널 열기 | 작성 중인 다른 내용이 있으면 확인 창 |
| **저장**(패널 상단) | 입력 완료 후 | 신규는 등록, 수정은 갱신 | 단자 품목·전선 사이즈 누락, 하한>상한이면 비활성 |
| **취소**(패널 상단) | 입력 중단 | 패널 닫기 | 변경 내용이 있으면 확인 창 |
| **연필 아이콘** | 기존 규격 수정 | 해당 행 값으로 패널 채우기 | — |
| **휴지통 아이콘** | 규격 삭제 | 확인 창 후 삭제 | 삭제 후 되돌릴 수 없음 |
| **검색창** | 단자품목·전선사이즈·전선품목·어플리케이터로 찾기 | 서버 검색(부분 일치) | 입력 시 1페이지로 이동 |
| **단자 종류 / 사용여부 필터** | 목록 좁히기 | 서버 필터 | 기본 사용여부 = `사용` |
| **페이지 이동(◀ ▶)** | 100건 넘을 때 | 서버 페이징 | 총 건수 표시 |

## 업무 흐름
1. [품목마스터]에 단자 품목(및 전선 품목)이 원자재로 등록되어 있는지 확인합니다.
2. [추가]를 누르고 **단자 품목**과 **전선 사이즈**를 지정합니다.
3. 단자 제조사 규격서나 공정 조건서를 보고 압착고·압착폭·절연부 압착고·인장력·탈피길이 값을 입력합니다.
4. [저장]합니다. 목록에 행이 추가되면 값이 맞는지 다시 확인합니다.
5. 규격이 바뀌면 행을 클릭해 수정하고, 더 이상 쓰지 않는 규격은 삭제 대신 **사용여부를 미사용**으로 바꿔 이력을 남깁니다.

## 입력 규칙 / 검증
- 단자 품목과 전선 사이즈는 필수입니다.
- 같은 단자 품목 + 같은 전선 사이즈는 **한 건만** 등록됩니다(중복 시 저장 오류).
- 각 항목의 하한은 상한보다 클 수 없습니다.
- 숫자는 소수 셋째 자리까지 저장됩니다.

## 자주 묻는 질문
- **Q.** 단자 종류 목록에 필요한 종류가 없어요.
  **A.** 공통코드 `TERMINAL_TYPE`에 추가하면 바로 선택할 수 있습니다. 초기에는 디스크·링·파스톤·핀·소켓 5종만 있습니다.
- **Q.** 자주검사 화면에서 이 규격이 자동으로 적용되나요?
  **A.** 현재는 규격을 등록해 두는 단계입니다. 검사 화면 연동은 이후 단계에서 연결됩니다.
- **Q.** 값 하나만 알고 나머지는 모릅니다.
  **A.** 아는 값만 넣고 나머지는 비워 두세요. 비운 항목은 판정에서 제외됩니다.
