# AQL 기준관리

## 화면 목적
수입검사(IQC)에서 입고 LOT을 **샘플링검사**로 합격/불합격 판정하기 위한 기준을 등록·관리합니다.
LOT 전체를 검사하지 않고 일부 표본만 검사하므로, "표본을 몇 개 뽑고(샘플수), 그중 불량이 몇 개까지면 합격(Ac)·몇 개부터 불합격(Re)인가"를 정해 두어야 합니다. 이 기준의 묶음이 **AQL 정책**과 **AQL 기준**입니다.

> AQL(Acceptable Quality Limit, 합격품질한계): LOT을 합격으로 인정할 수 있는 허용 불량 수준입니다. **값이 작을수록 더 엄격**합니다(예: 1.0이 2.5보다 엄격).

## 화면 구성
- **왼쪽 — AQL 정책관리**: 품목에 직접 연결되는 단위. Major(중결함)·Minor(경결함)별로 어떤 AQL 기준을 쓸지 묶습니다.
- **오른쪽 위 — AQL 기준 목록**: AQL 값 단위의 기준. 정책이 이 기준을 참조합니다.
- **오른쪽 아래 — LOT 수량별 판정기준**: 선택한 AQL 기준에 대해 LOT 크기 구간별 샘플수·Ac·Re를 정의합니다.

## 개념 관계
```
품목마스터 ──연결──▶ AQL 정책 ──(Major/Minor)──▶ AQL 기준 ──▶ LOT 수량별 판정기준(샘플수·Ac·Re)
```

## ① AQL 정책 컬럼 (IQC_AQL_POLICIES)

| 컬럼 | 역할 / 의미 |
|------|------|
| **정책 코드(policyCode)** | 정책을 식별하는 고유 코드입니다. **품목마스터의 'AQL 정책' 필드가 이 코드를 참조**합니다. 예: `AQLP-II-1.0-2.5`. 등록 후에는 변경할 수 없습니다. |
| **정책명(policyName)** | 사람이 알아보기 위한 이름입니다. 예: `II Major 1.0 Minor 2.5`. |
| **검사수준(inspectionLevel)** | 표본 크기를 결정하는 수준입니다. 일반적으로 **II(보통검사)**를 씁니다. I은 더 적게(완화), III은 더 많이(엄격) 뽑습니다. LOT 크기와 검사수준이 만나 샘플 크기가 정해집니다. |
| **Major AQL(majorAqlCode)** | **중결함**(기능·안전에 영향이 큰 결함)에 적용할 AQL 기준을 선택합니다. 오른쪽 'AQL 기준 목록'의 항목 중 하나를 고릅니다. 보통 Minor보다 엄격한(값이 작은) 기준을 씁니다. |
| **Minor AQL(minorAqlCode)** | **경결함**(외관 등 경미한 결함)에 적용할 AQL 기준을 선택합니다. 보통 Major보다 느슨한 기준을 씁니다. |
| **치명결함 처리(criticalMode)** | **치명결함(Critical)** 발생 시 처리 방식입니다. `IMMEDIATE_FAIL`은 치명결함이 1개라도 나오면 샘플수·Ac와 무관하게 **즉시 LOT 불합격**으로 판정합니다. |
| **사용여부(useYn)** | `Y`일 때만 품목 연결·검사에 사용됩니다. `N`이면 비활성(사용 중지). |
| **비고(remark)** | 관리용 메모입니다. |

## ② AQL 기준 컬럼 (AQL_STANDARDS)

| 컬럼 | 역할 / 의미 |
|------|------|
| **AQL 코드(aqlCode)** | AQL 기준을 식별하는 고유 코드입니다. 정책의 Major/Minor가 이 코드를 참조합니다. 예: `AQL-1.0`. 등록 후 변경 불가. |
| **AQL 명칭(aqlName)** | 기준의 이름입니다. 예: `일반검사 AQL 1.0`. |
| **검사수준(inspectionLevel)** | 이 기준이 전제하는 검사수준입니다(보통 II). |
| **AQL 값(aqlValue)** | **합격품질한계 수치**입니다(예: 0.65, 1.0, 2.5). 허용 불량률의 상한을 뜻하며 **작을수록 엄격**합니다. 이 값과 샘플수가 만나 Ac/Re가 결정됩니다. |
| **사용여부(useYn)** | `Y`일 때만 정책에서 선택할 수 있습니다. |
| **비고(remark)** | 관리용 메모입니다. |

## ③ LOT 수량별 판정기준 (rules)

같은 AQL 값이라도 **LOT가 크면 더 많이 뽑아야** 하므로, LOT 크기 구간마다 샘플수·Ac·Re를 따로 정의합니다.

| 컬럼 | 역할 / 의미 |
|------|------|
| **lotQtyFrom** | 이 행이 적용되는 LOT 수량 구간의 **시작값(하한)**입니다. |
| **lotQtyTo** | 이 행이 적용되는 LOT 수량 구간의 **끝값(상한)**입니다. (예: 51~500) |
| **sampleSize (n)** | 그 구간의 LOT에서 **뽑아 검사할 표본 개수**입니다. |
| **acceptQty (Ac)** | **합격판정개수**. 검사 불량수가 **Ac 이하**이면 LOT 합격입니다. |
| **rejectQty (Re)** | **불합격판정개수**. 검사 불량수가 **Re 이상**이면 LOT 불합격입니다. (보통 Re = Ac + 1) |
| **정렬순서(sortOrder)** | 행 표시 순서입니다. 저장 시 LOT 수량 순으로 자동 정리됩니다. |

> 판정 예시: 샘플수 n=13, Ac=1, Re=2 → 표본 13개 중 불량 **1개까지는 합격**, **2개부터 불합격**.

## 사용 순서
1. 오른쪽 **AQL 기준**을 먼저 등록합니다(예: `AQL-1.0`, `AQL-2.5`). 각 기준에 **LOT 수량별 판정기준**(샘플수·Ac·Re)을 채웁니다.
2. 왼쪽 **AQL 정책**을 만들고 **Major/Minor**에 위 기준을 연결합니다.
3. [품목마스터]에서 품목의 **AQL 정책** 필드에 이 정책을 지정합니다.
4. 이후 해당 품목 입고 LOT의 수입검사에서 이 기준으로 자동 판정됩니다.

## 입력 규칙 / 검증
- LOT 수량 From은 To보다 클 수 없습니다.
- Re 수량은 Ac 수량보다 커야 합니다.
- LOT 수량 구간끼리 겹칠 수 없습니다(앞 구간의 To보다 다음 구간의 From이 커야 함).

## 자주 묻는 질문
- **Q.** Major와 Minor를 왜 따로 두나요?
  **A.** 결함의 심각도에 따라 합격 기준을 다르게 적용하기 위해서입니다. 보통 중결함(Major)은 엄격하게(작은 AQL), 경결함(Minor)은 느슨하게 둡니다.
- **Q.** LOT 수량별 판정기준은 왜 필요한가요?
  **A.** LOT가 클수록 더 많은 표본을 검사해야 같은 신뢰수준을 얻기 때문입니다(KS Q ISO 2859-1 샘플링 표 기준).
- **Q.** 정책을 비워두면(품목에 미연결) 어떻게 되나요?
  **A.** AQL 자동 판정이 적용되지 않습니다(무검사 또는 수동 판정).
