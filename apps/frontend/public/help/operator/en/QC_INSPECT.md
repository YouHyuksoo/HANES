# Visual Inspection — Operator Guide

## System Purpose & Role
This screen manages **visual inspection** results for finished goods (FG). Scan the FG barcode, judge pass/fail, and record defect codes and details on failure.

| Result | FG_LABELS Transition | Description |
|--------|---------------------|-------------|
| PASS | `ISSUED` → `VISUAL_PASS` | Visually OK, can proceed to next process (packing) |
| FAIL | `ISSUED` → `VISUAL_FAIL` | Defect found, subject to re-inspection or void |

## Data Structure
```
FG_LABELS (PK: FG_BARCODE)
   State transition: ISSUED → VISUAL_PASS/VISUAL_FAIL → PACKED → SHIPPED
   VISUAL_PASS on pass, VISUAL_FAIL on fail

INSPECT_RESULTS (PK: RESULT_NO, SeqGenerator INSPECT_RESULT)
   ├─ FG_BARCODE ─▶ FG_LABELS (scanned FG barcode)
   ├─ PASS_YN: Y/N (pass/fail)
   ├─ ERROR_CODE: defect code (common code VISUAL_DEFECT)
   └─ INSPECT_TYPE: 'VISUAL'
```

## Screen Layout
- **Main left area**: DataGrid — inspection history (FG barcode, judgment, defect code, inspect time, inspector)
  - Summary stats: total, inspected, pending, pass rate
  - Search: order no, item code; status/judgment filters
  - FG label select modal: `FgLabelSelectModal` — select from ISSUED-status FG list
- **Right slide panel**: `InspectFormPanel` — inspection form (auto-opens on barcode scan)
  - Product info: FG barcode, item code, order no, equip code, status (read-only)
  - PASS/FAIL buttons (large toggle)
  - Defect checklist: `VISUAL_DEFECT` common code items with checkbox + qty
  - Main defect code: `VISUAL_DEFECT` selector
  - Detail reason: free text input

## Inspection Flow

### ① Scan FG Barcode
`GET /quality/continuity-inspect/fg-label/{barcode}`
- Enter barcode in the scan input field → Enter
- FG_LABELS lookup → product info displayed + right panel opens
- Already-inspected labels (`status !== ISSUED`): `Already Inspected` warning + Save disabled

### ② Pass/Fail Judgment
`POST /quality/continuity-inspect/visual-inspect/{fgBarcode}`
- **PASS**: Click large green button → saves with `passYn: "Y"`
- **FAIL**: Click large red button → enter defect code + detail reason → save
- Transactional: `InspectResult` created + `FgLabel.status` updated atomically

### ③ Verify Result
- Inspection history DataGrid auto-refreshes
- FG_LABELS status changes to `VISUAL_PASS` or `VISUAL_FAIL`
- `VISUAL_PASS` → box packing available at `/shipping/pack`
- `VISUAL_FAIL` → re-inspection or void processing

## FG_LABELS State Transition

| Status | Meaning | Next Status |
|--------|---------|-------------|
| `ISSUED` | Label issued, uninspected | `VISUAL_PASS` or `VISUAL_FAIL` |
| `VISUAL_PASS` | Visual inspection passed | `PACKED` (packing) |
| `VISUAL_FAIL` | Visual inspection failed | Re-inspect (return to ISSUED) or void |
| `PACKED` | Packing complete | `SHIPPED` |
| `SHIPPED` | Shipped | Terminal state |
| `VOIDED` | Voided | Terminal state |

## Prerequisites (Master·Common Code)
- Common codes: `VISUAL_DEFECT` (visual defect codes) — used for defect selection and checklist
- FG_LABELS: Must be pre-created in `ISSUED` status via continuity inspect (`/inspection/result`) or direct FG issue
- INSPECT_RESULTS: SeqGenerator `INSPECT_RESULT` must be registered in SEQ_RULES

## Permissions
Quality inspector (visual inspection register/view). Administrators can modify/delete (deletion only when linked prod result is CANCELED).

## Troubleshooting
| Symptom | Cause | Action |
|------|------|------|
| Barcode scan returns nothing | Barcode not in FG_LABELS | Verify FG barcode issuance or use label selection modal |
| Inspection save blocked — already inspected | `FG_LABELS.status` is not ISSUED | Duplicate inspection not allowed |
| Defect code not selectable on failure | `VISUAL_DEFECT` common code not registered | Register visual defect codes in common codes |
| Recent inspection not shown in list | Before auto-refresh | DataGrid auto-refreshes on save; manual refresh available |
| No labels in FG selection modal | All FG not in ISSUED status | Verify target FG has ISSUED status |
| Inspection result cannot be deleted | Prod result not in CANCELED status | Delete only possible after prod result cancellation |
